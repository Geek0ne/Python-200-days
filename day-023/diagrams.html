sequenceDiagram participant C as 代码 participant P as Python 解释器 participant M as 内存 Note over C: @decorator<br/>def func(): ... C->>P: 解析 def func() P->>M: 创建函数对象 func C->>P: 遇到 @decorator P->>P: func = decorator(func) P->>M: func 指向 wrapper M-->>C: func 已被替换 Note over C: 现在 func = wrapper<br/>wrapper 闭包捕获了原始 func
