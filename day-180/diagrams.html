测试覆盖率类型

语句覆盖 (Statement):
    if x:        → 需要 x=True 才能执行 if 体
        print()

分支覆盖 (Branch):
    if x:         → 需要 x=True 和 x=False 两个分支
        print()
    → 语句 + 分支

条件覆盖 (Condition):
    if x and y:  → 每个条件独立测试 True/False
        print()

路径覆盖 (Path):
    if x:        → 所有可能执行路径
        if y:
            print()
graph TD A[开始] --> B{x} B -->|True| C{y} B -->|False| D[结束] C -->|True| E[打印] C -->|False| D E --> D 
graph TD

路径分析： - 路径 1: Start → x=True → y=True → print → End - 路径 2: Start → x=True → y=False → End - 路径 3: Start → x=False → End
