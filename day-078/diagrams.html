指标类型：
  Counter:   请求数、错误数（只增不减）
  Histogram: 响应时间分布
  Gauge:     当前并发数、队列长度

🔄 布隆过滤器原理

插入元素 "apple"：
  Hash1("apple") = 3  ──▶ 位数组[3] = 1
  Hash2("apple") = 7  ──▶ 位数组[7] = 1
  Hash3("apple") = 11 ──▶ 位数组[11] = 1

位数组状态：[0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0, 1, ...]
                         ↑         ↑              ↑
                         3         7              11

查询 "apple"：
  Hash1("apple") = 3  ──▶ 位数组[3] == 1 ✓
  Hash2("apple") = 7  ──▶ 位数组[7] == 1 ✓
  Hash3("apple") = 11 ──▶ 位数组[11] == 1 ✓
  全部为 1 → 可能存在（有小概率误判）

查询 "banana"：
  Hash1("banana") = 5 ──▶ 位数组[5] == 0 ✗
  直接返回 False → 一定不存在（无误判）

⚡ 批量写入 vs 单条写入

单条写入：
  DB调用  DB调用  DB调用  DB调用  DB调用  DB调用 ...
  ──────  ──────  ──────  ──────  ──────  ──────
  10ms    10ms    10ms    10ms    10ms    10ms
  总计: 60ms (100条数据)

批量写入：
  缓冲  缓冲  缓冲  缓冲  ──▶ DB批量写入
  ───── ───── ───── ─────      ──────────
  0ms   0ms   0ms   0ms       15ms
  总计: 15ms (100条数据)

性能提升: 4x
