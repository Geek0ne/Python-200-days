Matplotlib vs Plotly 对比

          Matplotlib                    Plotly
     ┌─────────────────┐          ┌─────────────────┐
     │   静态渲染       │          │   交互式渲染      │
     │   PNG/PDF/SVG   │          │   HTML/图片       │
     ├─────────────────┤          ├─────────────────┤
     │ ✅ 极高自定义     │          │ ✅ 原生交互       │
     │ ✅ 论文/报告     │          │ ✅ Web/仪表盘     │
     │ ✅ 轻量文件       │          │ ✅ 动画支持       │
     │ ❌ 无交互       │          │ ❌ 文件较大       │
     │ ❌ 部署复杂     │          │ ❌ 自定义受限      │
     └─────────────────┘          └─────────────────┘
              │                            │
              └──────────┬─────────────────┘
                         │
                    ┌────▼────┐
                    │  Seaborn │ ← 基于 Matplotlib 的高层 API
                    │  Dash    │ ← 基于 Plotly 的 Web 框架
                    └─────────┘
