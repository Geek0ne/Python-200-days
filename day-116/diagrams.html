CNN 整体架构

输入: 3×32×32 (RGB)
    │
    ▼ Conv2d(3→32, 3×3) + BN + ReLU
特征图: 32×32×32  ← 每个通道检测一种特征
    │
    ▼ MaxPool2d(2×2)
下采样: 32×16×16  ← 尺寸减半
    │
    ▼ Conv2d(32→64, 3×3) + BN + ReLU
特征图: 64×16×16  ← 更丰富的特征
    │
    ▼ MaxPool2d(2×2)
下采样: 64×8×8
    │
    ▼ Conv2d(64→128, 3×3) + BN + ReLU
特征图: 128×8×8  ← 高级特征
    │
    ▼ MaxPool2d(2×2)
下采样: 128×4×4
    │
    ▼ Flatten: 128×4×4 = 2048
    │
    ▼ Linear(2048→256) + ReLU + Dropout
    │
    ▼ Linear(256→10)
    │
    ▼ 输出: 10 个类别的 logits

BatchNorm 工作原理

输入特征图 (batch=4, channel=3, H=8, W=8)
    │
    ▼ 对每个 channel 分别计算:
    │   mean_c = 1/(N×H×W) Σ x[n,c,h,w]
    │   var_c  = 1/(N×H×W) Σ (x[n,c,h,w] - mean_c)²
    │
    ▼ 归一化:
    │   x_hat = (x - mean_c) / √(var_c + ε)
    │
    ▼ 缩放和平移（可学习参数）:
    │   y = γ × x_hat + β
    │
    ▼ 输出: 同形状，均值≈0，方差≈1
