Day 117 — 迁移学习 (Transfer Learning)

🎯 今日目标：掌握迁移学习的核心思想，学会使用预训练模型进行微调，实现自定义图片分类

一、什么是迁移学习？

1.1 核心思想

迁移学习（Transfer Learning）是指将在大规模数据集上训练好的模型，迁移到目标任务上使用。

为什么需要迁移学习？

  • 从头训练一个深度学习模型需要海量数据和大量计算资源
  • 真实场景中，我们往往只有少量标注数据
  • 预训练模型已经在 ImageNet（1400万张图片，1000个类别）上学到了通用的视觉特征
  • 我们可以复用这些通用特征，只需要针对目标任务微调

1.2 类比理解

人类学习 vs 迁移学习
─────────────────────────────────────
人类：学了英语 → 学法语更容易（语言知识迁移）
模型：在 ImageNet 训练 → 识别医学影像更容易（视觉特征迁移）

关键点：底层特征（边缘、纹理）是通用的

2.1 常见预训练模型

模型 参数量 Top-1 准确率 特点 适用场景

三、迁移学习的两种核心策略

3.1 策略对比

策略一：特征提取（Feature Extraction）
═══════════════════════════════════════════
┌─────────────────────────┐
│   冻结预训练模型的卷积层  │  ← 不更新权重
│   只训练最后的分类层      │  ← 只更新这一部分
└─────────────────────────┘
优点：训练快、数据需求少
缺点：特征可能不匹配

策略二：微调（Fine-tuning）
═══════════════════════════════════════════
┌─────────────────────────┐
│   解冻部分/全部预训练层   │  ← 用小学习率更新
│   用更小的学习率训练      │  ← 避免破坏已有特征
│   同时训练新的分类层      │
└─────────────────────────┘
优点：效果更好、适应性更强
缺点：需要更多数据、训练更慢

3.2 如何选择？

场景 推荐策略 原因
数据量 < 1000 张 特征提取 数据太少，微调容易过拟合
数据量 1000~10000 张 微调（冻结前几层） 平衡效果与稳定性
数据量 > 10000 张 全量微调 数据充足，可以充分训练
目标任务与源任务相似 特征提取 通用特征已经很有效
目标任务与源任务差异大 全量微调 需要调整更多层的特征

四、微调（Fine-tuning）详解

4.1 微调的关键技巧

python
# 技巧 1：分层学习率（Layer-wise Learning Rate）
# 底层特征更通用 → 学习率更小
# 高层特征更任务相关 → 学习率更大

# 技巧 2：渐进式解冻（Gradual Unfreezing）
# 先训练分类头 → 冻结 → 解冻最后几层 → 逐步解冻更多层

# 技巧 3：差分学习率（Discriminative Learning Rates）
# 不同层使用不同的学习率

微调流程

  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
  │ 加载预训练模型 │ →  │ 修改分类头    │ →  │ 冻结卷积层    │
  │ (ImageNet)   │    │ (适配任务)    │    │              │
  └──────────────┘    └──────────────┘    └──────────────┘
         │                                        │

五、API 速查表

5.1 PyTorch 迁移学习核心 API

python
# 1. 加载预训练模型
import torchvision.models as models
model = models.resnet50(weights='IMAGENET1K_V2')

# 2. 冻结所有参数
for param in model.parameters():
    param.requires_grad = False

# 3. 修改分类头（替换最后的全连接层）
model.fc = nn.Linear(model.fc.in_features, num_classes)

# 4. 只训练分类头的参数
trainable_params = filter(lambda p: p.requires_grad, model.parameters())

# 5. 差分学习率
optimizer = Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 1e-3},
])

# 6. 解冻指定层
for param in model.layer4.parameters():
    param.requires_grad = True

八、思考题

  1. 为什么迁移学习有效？ 从特征复用的角度思考，预训练模型的浅层和深层分别学到了什么？

参考答案

因为深度网络学到的特征是分层、可复用的：

  • 浅层：学的是通用低级特征——边缘、角点、颜色、纹理。这些对几乎任何视觉任务都有用，与具体类别无关。
  • 深层：学的是任务相关的高级语义——ImageNet 里各种物体的部件和类别模式。

在 ImageNet（约 1400 万张图）上预训练的模型，已经把这些通用滤波器学得很好了。迁移到你的任务时，不必再用小数据集从头学「什么是边缘」，只需复用浅中层、微调深层并换一个新的分类头。于是数据需求少、训练快、收敛稳、泛化更好。类比：学过英语再学法语更容易。

小例子：只有 200 张猫狗照片，从头训练会严重过拟合；冻结 ResNet 卷积层、只训练分类头，很快就能达到不错准确率。

⚠️ 注意：源域与目标域越接近（都是自然图像）效果越好；差异很大（如医学灰度图）时需要更多微调甚至换预训练源。

  1. 学习率的选择：在微调预训练模型时，为什么底层的学习率要小于顶层？如果所有层用相同的学习率会怎样？

参考答案

底层保存的是通用且已经很好的特征，大改动会破坏这些有用的滤波器（相当于「忘掉」预训练成果）；而顶层和新分类头是任务相关、甚至随机初始化的，需要较大更新才能快速适配。所以用差分学习率：底层小、顶层大。

如果所有层用同一个学习率：

  • 同用大学习率 → 小数据集的噪声会把底层通用特征冲掉，失去迁移优势、过拟合、训练不稳。
  • 同用小学习率 → 新分类头学得太慢，收敛拖沓。

小例子：冻结 conv1~layer2，layer3 用 1e-5、layer4 用 1e-4、fc 用 1e-3，既保住通用特征又让新头快速学习。

💡 提示：配合「渐进式解冻」——先只训分类头，再逐步解冻更深的块并配小学习率，更稳。

  1. 数据增强策略：当目标任务的数据量很小时，除了迁移学习，还有哪些数据增强策略可以提升效果？

参考答案

数据增强通过「制造合理变体」变相扩充数据、抑制过拟合：

  • 几何变换：随机裁剪、翻转、旋转、平移、缩放。
  • 光度变换：颜色抖动（ColorJitter）、亮度/对比度调整、加噪声、模糊。
  • 进阶混合：Mixup（两张图及标签按比例混合）、CutMix（贴一块图补丁）、RandAugment/AutoAugment（自动搜索增强策略）。
  • 生成式：用 GAN/扩散模型合成新样本。
  • 测试时增强（TTA）：对同一张图的多个增强版本预测再平均，提升稳健性。

此外还有非增强手段：正则化（Dropout、权重衰减）、早停、交叉验证、类别平衡。

小例子：200 张图加上 RandomHorizontalFlip + RandomCrop(padding=4) + ColorJitter，每个 epoch 模型看到的「版本」都不同，过拟合明显减轻。

⚠️ 注意：增强必须保持标签不变——文字/数字翻转可能改变含义，医学影像不能过度扭曲。

  1. 模型选择：在资源受限的移动端设备上部署图像分类模型，你会选择 ResNet-18、EfficientNet-B0 还是 MobileNet？为什么？

参考答案

优先 MobileNet（尤其 V3-small）。它专为移动端设计，用深度可分离卷积大幅降低参数量和计算量（FLOPs），延迟低、体积小，精度/算力比优秀。

对比：

  • EfficientNet-B0：复合缩放也很高效，精度略高，但比 MobileNet 稍重，适合「能多给一点算力换精度」的场景。
  • ResNet-18：通用基线，结构简单、生态好，但在移动端偏重偏慢，资源不算紧张时才考虑。

选型要看：参数量、FLOPs、延迟、内存、是否支持 INT8 量化、目标硬件（NPU/GPU）。

小例子：MobileNetV3-small 约 2.5M 参数，ResNet-18 约 11.7M——前者在手机上推理快得多（具体耗时因设备而异）。

💡 提示：还可叠加量化、剪枝、知识蒸馏进一步压缩，并务必在真机上实测延迟。

  1. 负迁移（Negative Transfer）：在什么情况下迁移学习可能比从头训练效果更差？如何避免？

参考答案

当源域和目标域差异太大时，迁移来的特征反而帮倒忙，即负迁移。典型情况：

  • 预训练于自然 RGB 图像，目标却是灰度医学/卫星/工业缺陷图，低级统计特性完全不同。
  • 源任务的偏置与目标冲突（如粗粒度分类 → 细粒度识别）。
  • 目标数据极少却激进地微调全部层，把通用特征破坏掉。

表现：迁移模型还不如从头训练或简单基线。

避免办法：评估域相似度；差异大时多冻结层、用更小学习率；选更接近的预训练源（如医学预训练模型）；始终和从头训练基线对比以发现负迁移；渐进解冻；必要时用域自适应，或在目标域数据上做自监督预训练，实在不相关就从头训练。

小例子：ImageNet→胸片分类，若激进微调所有层可能不如预期；冻结浅层 + 小学习率通常更稳。

⚠️ 注意：一定要跑一个「从头训练」基线做对照，否则可能察觉不到负迁移。
