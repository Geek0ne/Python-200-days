2. SQLi：数据变成代码

正常:
  SELECT id,name,price FROM products WHERE id = 1
                                              ↑ 数据

注入 1':
  SELECT id,name,price FROM products WHERE id = 1'
                                                 ↑ 引号提前闭合
  → unrecognized token: "'"
  → 500 + "SQL error: ..."        ← 检测信号

参数化:

  SQL 模板: SELECT ... WHERE id = ?
  参数:     ["1'"]
  数据库把 "1'" 当纯数据 → 不会报错

3. XSS：转义只改变表示

输入 payload:
  <svg/onload=alert('LPX123')>

/search（漏洞）响应:
  <p>Results for: <svg/onload=alert('LPX123')></p>
                   └──────── 原始 payload 存在 ────────┘
  → 浏览器执行 → 真阳性

/safe-search（修复）响应:
  <p>Results for: &lt;svg/onload=alert('LPX123')&gt;</p>
                   └─ 文本仍是 alert，但 < 已转义 ─┘
  → 不执行 → 若按关键字判定就是假阳性

4. 误报演练结果

endpoint           naive  precise  has_alert   raw  escaped
/search             True     True       True  True    False
/safe-search        True    False       True  False    True
                    ↑        ↑
                 误报      正确

naive:   2 命中 / 1 假阳性
precise: 1 命中 / 0 假阳性

5. 本日真实扫描结果

findings: 6
