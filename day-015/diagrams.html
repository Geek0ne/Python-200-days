│  │ sort_and_dedup(data) → 排序并去重，返回统计信息             │  │
│  │ percentiles(data, percents) → 计算任意分位数                 │  │
│  │ visual_histogram(data, bins) → 终端字符直方图               │  │

│  │   ├─ 极差 | Q1 | Q3 | IQR                                   │  │
