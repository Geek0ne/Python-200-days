异常点：路径短（2-3次分割即被隔离）
正常点：路径长（需要多次分割）

异常分数计算

异常分数公式：

    s(x, n) = 2^( -E(h(x)) / c(n) )

其中：
    ┌─────────────────────────────────────────────────┐
    │  h(x)      = x 的路径长度（从根到叶的边数）       │
    │  E(h(x))   = 多棵树的平均路径长度                 │
    │  c(n)      = BST 平均路径长度（归一化因子）        │
    │  c(n)      = 2H(n-1) - 2(n-1)/n                 │
    │  H(i)      = ln(i) + 0.5772 (欧拉常数)           │
    └─────────────────────────────────────────────────┘

分数解读：
    ┌──────────────────────────────────────┐
    │  s → 1.0  ████████████████ 高度异常  │
    │  s → 0.5  ████████        正常       │
    │  s → 0.0  ░░░░            非常正常   │
    └──────────────────────────────────────┘

常见异常模式：
┌────────────────┬──────────────────────────────┐
│ DDoS 攻击      │ 高 SYN 比 + 短持续时间 + 小包  │
│ 端口扫描       │ 大量不同目标端口 + RST 响应多   │
│ 数据泄露       │ 上行流量异常大 + 长持续时间      │
│ 暴力破解       │ 大量登录失败 + 短间隔重复请求    │
└────────────────┴──────────────────────────────┘

┌─────────────────┬──────────┬──────────┬──────────┬──────────┐

推荐选择：
  通用场景 → Isolation Forest（首选）
  局部异常 → LOF
  序列数据 → Autoencoder / LSTM
  快速筛选 → Z-Score / IQR
