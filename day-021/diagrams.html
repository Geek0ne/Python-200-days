1. 迭代器协议流程图

完整的协议交互

┌──────────────────────────────────────────────────┐
│                  可迭代对象                        │
│  ┌────────────────────────────────────────────┐  │
│  │  __iter__(self) → 返回迭代器对象            │  │
│  │  或 __getitem__(self, index) → 按索引取值   │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────┬───────────────────────────┘
                       │  iter()
                       ▼
┌──────────────────────────────────────────────────┐
│                   迭代器                           │
│  ┌────────────────────────────────────────────┐  │
│  │  __iter__(self) → return self              │  │
│  │  __next__(self) → return value             │  │
│  │                 → raise StopIteration      │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────┬───────────────────────────┘
                       │  next()
                       ▼
              ┌─────────────────┐
              │    返回值        │
              │  或 StopIteration│
              └─────────────────┘

2. for 循环底层实现拆解

Python 代码:
    for x in iterable:
        print(x)

底层展开:
                         ┌──────────────────┐
                         │  开始 for 循环    │
                         └────────┬─────────┘
                                  │
                                  ▼
                     ┌────────────────────────┐
                     │  _it = iter(iterable)  │
                     │  # 调用 __iter__()     │
                     └────────┬───────────────┘
                              │
                              ▼
                     ┌────────────────────────┐
                     │  while True:           │
                     └────────┬───────────────┘
                              │
                              ▼
                     ┌────────────────────────┐
                     │  try:                  │
                     │    x = next(_it)       │
                     │    # 调用 __next__()   │
                     └────────┬───────────────┘
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
           ┌────────────────┐  ┌──────────────────┐
           │ 没有异常        │  │ StopIteration    │
           │ 执行循环体      │  │ 跳出循环          │
           └───────┬────────┘  └────────┬─────────┘
                   │                    │
                   └──── 继续 ──────────┘
                                        │
                                        ▼
                              ┌──────────────────┐
                              │  del _it         │
                              │  # 清理迭代器    │
                              └──────────────────┘

3. 可迭代对象 vs 迭代器 关系

                    ┌─────────────────────┐
                    │   可迭代对象         │
                    │   Iterable          │
                    │                     │
                    │   可以 for 循环      │
                    │   有 __iter__()      │
                    │   iter(obj) 返回     │
                    └──────────┬──────────┘
                               │
             ┌─────────────────┼─────────────────┐
             │                 │                  │
             ▼                 ▼                  ▼
     ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
     │    列表      │  │    字符串    │  │    字典      │
     │ [1, 2, 3]    │  │   "hello"    │  │  {"a": 1}    │
     │ list_iterator│  │  str_iterator│  │  dict_keys   │
     └──────────────┘  └──────────────┘  └──────────────┘

                    ┌─────────────────────┐
                    │     迭代器           │
                    │   Iterator          │
                    │                     │
                    │  有 __iter__() = self│
                    │  有 __next__()      │
                    │  只能用一次          │
                    │  惰性求值            │
                    └─────────────────────┘

4. 迭代器状态机

                    ┌─────────────────┐
                    │   初始状态       │
                    │  (还未取值)      │
                    └────────┬────────┘
                             │  __next__()
                             ▼
                    ┌─────────────────┐
                    │   激活状态       │◄────┐
                    │  (有值可取)      │     │
                    └────────┬────────┘     │
                             │  __next__()  │  __next__()
                             ▼              │
                    ┌─────────────────┐     │
                    │   激活状态       │─────┘
                    │  (下一个值)      │
                    └────────┬────────┘
                             │  __next__() → StopIteration
                             ▼
                    ┌─────────────────┐
                    │   耗尽状态       │
                    │  (无法再取值)    │
                    └─────────────────┘

5. 迭代器 vs 列表 内存对比

列表方式（立即求值）:
    range(1000000) → [0, 1, 2, ..., 999999]
                     ┌───────────────────────────────┐
                     │  ↓ 立即分配                    │
                     │  约 8MB 内存                   │
                     └───────────────────────────────┘

迭代器方式（惰性求值）:
    iter(range(1000000)) → <range_iterator>
                     ┌───────────────────────────────┐
                     │  ↓ 几乎不占内存                │
                     │  56 字节                      │
                     │  ↓ 逐个生成                    │
                     │  0 → 1 → 2 → ... → 999999    │
                     │  ↓ 用完即弃                    │
                     └───────────────────────────────┘

7. 迭代器对象生命周期

sequenceDiagram participant Python as Python 代码 participant Iterable as 列表 [1,2,3] participant Iterator as list_iterator participant Value as 值 Python->>Iterable: iter([1,2,3]) Iterable->>Iterator: 创建 list_iterator Iterator-->>Python: 返回迭代器 loop 遍历元素 Python->>Iterator: next(it) Iterator-->>Value: 检查是否耗尽 alt 还有元素 Value-->>Iterator: 返回当前值 Iterator-->>Python: 返回值 (1, 2, 3) else 已耗尽 Value-->>Iterator: StopIteration Iterator-->>Python: 抛出 StopIteration end end Python->>Iterator: for 循环结束 Python->>Iterator: del it（自动） Note over Iterator: 迭代器对象被回收 
sequenceDiagram
    participant Python as Python 代码
    participant Iterable as 列表 [1,2,3]
    participant Iterator as list_iterator
    participant Value as 值

    Python->>Iterable: iter([1,2,3])
    Iterable->>Iterator: 创建 list_iterator
    Iterator-->>Python: 返回迭代器

    loop 遍历元素
        Python->>Iterator: next(it)
        Iterator-->>Value: 检查是否耗尽
        alt 还有元素
            Value-->>Iterator: 返回当前值
            Iterator-->>Python: 返回值 (1, 2, 3)
        else 已耗尽
            Value-->>Iterator: StopIteration
            Iterator-->>Python: 抛出 StopIteration
        end
    end

    Python->>Iterator: for 循环结束
    Python->>Iterator: del it（自动）
    Note over Iterator: 迭代器对象被回收

8. 迭代器协议接口图

classDiagram class Iterable { +__iter__() Iterator +__getitem__(index) Any } class Iterator { +__iter__() Iterator +__next__() Any } class Generator { +__iter__() Iterator +__next__() Any +send(value) Any +throw(exc_type) Any +close() None } Iterable <|-- Iterator : extends Iterator <|-- Generator : extends class List { +__iter__() list_iterator } class Str { +__iter__() str_iterator } class Dict { +__iter__() dict_keyiterator } Iterable <|-- List Iterable <|-- Str Iterable <|-- Dict 
classDiagram
    class Iterable {
        +__iter__() Iterator
        +__getitem__(index) Any
    }
    class Iterator {
        +__iter__() Iterator
        +__next__() Any
    }
    class Generator {
        +__iter__() Iterator
        +__next__() Any
        +send(value) Any
        +throw(exc_type) Any
        +close() None
    }

    Iterable <|-- Iterator : extends
    Iterator <|-- Generator : extends

    class List {
        +__iter__() list_iterator
    }
    class Str {
        +__iter__() str_iterator
    }
    class Dict {
        +__iter__() dict_keyiterator
    }

    Iterable <|-- List
    Iterable <|-- Str
    Iterable <|-- Dict
