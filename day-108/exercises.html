练习 5：不平衡数据处理

生成一个类别严重不平衡的数据集：

python
from sklearn.datasets import make_classification

X, y = make_classification(
    n_samples=5000,
    n_features=15,
    weights=[0.98, 0.02],  # 98% vs 2%
    random_state=42
)

分别用以下方式训练逻辑回归，对比性能： 1. 不处理不平衡（默认参数） 2. class_weight='balanced' 3. class_weight={0: 1, 1: 50}（手动权重）

评估指标： - Accuracy - Precision（正类） - Recall（正类） - F1（正类） - AUC

思考：为什么 Accuracy 在不平衡数据上会误导？哪个指标最能反映模型对少数类的识别能力？
