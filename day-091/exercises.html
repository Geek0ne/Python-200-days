练习 1：使用 cProfile 剖析

剖析以下函数，找出最耗时的部分：

python
def find_primes(n):
    """查找 n 以内的所有素数"""
    primes = []
    for num in range(2, n):
        is_prime = True
        for i in range(2, int(num ** 0.5) + 1):
            if num % i == 0:
                is_prime = False
                break
        if is_prime:
            primes.append(num)
    return primes
