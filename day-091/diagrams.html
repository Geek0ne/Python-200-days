性能剖析流程

┌─────────────────────────────────────────┐
│         性能剖析完整流程                 │
├─────────────────────────────────────────┤
│                                         │
│  1️⃣ 确定目标                           │
│     └→ 优化什么？为什么？               │
│     └→ 目标性能指标是什么？             │
│                                         │
│  2️⃣ 基准测试                           │
│     └→ 当前性能如何？                   │
│     └→ 用 timeit 建立基准               │
│                                         │
│  3️⃣ 剖析代码                           │
│     └→ cProfile → 找到热点函数         │
│     └→ line_profiler → 找到热点行      │
│                                         │
│  4️⃣ 分析结果                           │
│     └→ 哪些函数/行耗时最多？           │
│     └→ 为什么慢？                       │
│                                         │
│  5️⃣ 制定优化方案                       │
│     └→ 算法优化？数据结构？缓存？      │
│                                         │
│  6️⃣ 实施优化                           │
│     └→ 一次只改一个地方                │
│                                         │
│  7️⃣ 验证效果                           │
│     └→ 对比优化前后性能                │
│     └→ 确保没有引入 bug                │
│                                         │
└─────────────────────────────────────────┘

     3                                           def process_data(data):

分析:
• 第5行: 循环占 58.3% 时间 → 主要瓶颈

• 第7行: 追加占 7.8% 时间 → 合理

常见性能陷阱

┌─────────────────────────────────────────────┐
│           常见性能陷阱                       │
├──────────┬──────────────────────────────────┤
│ 循环中   │ ❌ for i in range(n):            │
│ 重复查找 │    if i in my_list: # O(n)!      │
│          │ ✅ my_set = set(my_list)         │
│          │    if i in my_set: # O(1)!       │
├──────────┼──────────────────────────────────┤
│ 字符串   │ ❌ result = ""                   │
│ 拼接     │    for s in strings:             │
│          │        result += s # 每次新建!    │
│          │ ✅ result = "".join(strings)     │
├──────────┼──────────────────────────────────┤
│ 重复     │ ❌ for i in range(n):            │
│ 计算     │    x = expensive_calc(i)         │
│          │ ✅ cache = {i: expensive_calc(i) │
│          │    for i in range(n)}            │
├──────────┼──────────────────────────────────┤
│ 在循环中 │ ❌ for i in range(n):            │
│ 创建对象 │    regex = re.compile(r'\d+')    │
│          │ ✅ regex = re.compile(r'\d+')    │
│          │    for i in range(n):            │
└──────────┴──────────────────────────────────┘

性能优化策略

优化策略优先级:
┌─────────────────────────────────────────┐
│  1. 算法优化 (最重要)                    │
│     O(n²) → O(n log n) → O(n)         │
├─────────────────────────────────────────┤
│  2. 数据结构选择                         │
│     list → set/dict (查找 O(n) → O(1)) │
├─────────────────────────────────────────┤
│  3. 减少遍历次数                         │
│     多次遍历 → 单次遍历                  │
├─────────────────────────────────────────┤
│  4. 缓存结果                             │
│     重复计算 → 缓存                      │
├─────────────────────────────────────────┤
│  5. 延迟加载                             │
│     提前加载 → 按需加载                  │
├─────────────────────────────────────────┤
│  6. 批量处理                             │
│     逐个处理 → 批量处理                  │
└─────────────────────────────────────────┘

timeit 基本用法:
┌─────────────────────────────────────────┐
│ # 代码字符串计时                         │
│ timeit.timeit('sum(range(1000))',       │
│               number=10000)             │
├─────────────────────────────────────────┤
│ # 函数计时                              │
│ timeit.timeit(my_func,                  │
│               number=10000)             │
├─────────────────────────────────────────┤
│ # 对比两种方法                          │
│ t1 = timeit.timeit(                     │
│     '[x**2 for x in range(1000)]',     │
│     number=10000)                       │
│ t2 = timeit.timeit(                     │
│     'list(map(lambda x: x**2,          │
│     range(1000)))',                     │
│     number=10000)                       │
└─────────────────────────────────────────┘
