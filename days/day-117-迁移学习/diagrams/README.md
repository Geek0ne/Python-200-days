# Day 117 — 迁移学习 图解

## 1. 迁移学习整体流程

```mermaid
flowchart TD
    A[预训练模型<br/>ImageNet 1000类] --> B{冻结/解冻策略}
    B -->|特征提取| C[冻结所有卷积层<br/>只训练分类头]
    B -->|微调| D[冻结底层<br/>解冻高层+分类头]
    C --> E[训练分类头<br/>lr=1e-3]
    D --> F[差分学习率训练<br/>底层lr=1e-5<br/>高层lr=1e-4<br/>分类头lr=1e-3]
    E --> G[评估模型]
    F --> G
    G --> H{准确率达标?}
    H -->|是| I[保存模型<br/>部署推理]
    H -->|否| J[调整策略<br/>解冻更多层/调学习率]
    J --> B
```

```
迁移学习策略:
  ✅ 冻结 Layer 1-2（通用特征，不需要调整）
  ⚠️ 冻结或微调 Layer 3-4（看数据量决定）
  ✅ 解冻 Layer 5+（任务相关，需要调整）
  ✅ 从头训练分类头（类别数不同）
```

## 5. 模型性能对比

```
模型性能对比（ImageNet 验证集）
═══════════════════════════════════════════════════════════

模型            参数量      准确率     速度      推荐场景
─────────────────────────────────────────────────────────
ResNet-18      11.7M      69.8%     ⚡⚡⚡     快速实验/移动端
ResNet-50      25.6M      76.1%     ⚡⚡       通用任务首选
ResNet-152     60.2M      78.3%     ⚡         高精度要求
VGG-16         138M       71.6%     ⚡         特征提取/风格迁移
EfficientNet-B0  5.3M     77.1%     ⚡⚡⚡     资源受限场景
EfficientNet-B4  19M      82.9%     ⚡⚡       通用高精度任务

选择建议:
  🚀 快速原型 → ResNet-18 或 EfficientNet-B0
  🎯 通用任务 → ResNet-50
  🏆 高精度   → EfficientNet-B4 或 ResNet-152
  📱 移动端   → MobileNetV3 或 EfficientNet-B0
```
