## 🔍 查漏补缺：常见知识盲区

### 盲区 1：装饰器 vs 闭包

```python
# 闭包 = 函数 + 捕获的变量
def outer(x):
    def inner(y):
        return x + y
    return inner

# 装饰器 = 闭包的特殊应用（接收函数，返回函数）
def decorator(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

### 盲区 2：生成器 vs 迭代器

```python
# 迭代器：实现了 __iter__() + __next__() 的对象
# 生成器：用 yield 语法创建的迭代器（更简洁）

# 迭代器
class Count:
    def __init__(self, n):
        self.n = n
        self.current = 0
    def __iter__(self):
        return self
    def __next__(self):
        if self.current >= self.n:
            raise StopIteration
        self.current += 1
        return self.current

# 生成器（等价写法）
def count(n):
    for i in range(1, n + 1):
        yield i
```

### 盲区 3：深拷贝 vs 浅拷贝

```python
import copy

a = [[1, 2], [3, 4]]

b = a              # 引用（同一个对象）
c = copy.copy(a)   # 浅拷贝（外层独立，内层共享）
d = copy.deepcopy(a)  # 深拷贝（完全独立）

a[0][0] = 999
# a → [[999, 2], [3, 4]]
# b → [[999, 2], [3, 4]]  (跟着变)
# c → [[999, 2], [3, 4]]  (内层共享，也变了！)
# d → [[1, 2], [3, 4]]    (完全独立)
```

### 盲区 4：多线程 vs 多进程 vs asyncio

```python
# GIL 限制：CPU 密集型 → 多进程；IO 密集型 → 多线程/asyncio

# 多线程（IO 密集型）
import threading
t = threading.Thread(target=io_task)
t.start()

# 多进程（CPU 密集型）
from multiprocessing import Process
p = Process(target=cpu_task)
p.start()

# asyncio（IO 密集型，单线程）
async def io_task():
    await asyncio.sleep(1)
```

### 盲区 5：dataclass vs 普通类

```python
from dataclasses import dataclass

# 普通类（需要写很多样板代码）
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    def __repr__(self):
        return f"Point(x={self.x}, y={self.y})"

# dataclass（自动生成 __init__, __repr__, __eq__ 等）
@dataclass
class Point:
    x: float
    y: float
```
