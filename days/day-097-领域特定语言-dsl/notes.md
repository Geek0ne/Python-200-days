# Day 097 学习笔记

## 核心概念

DSL（Domain Specific Language）是为特定领域设计的语言，比通用语言更精炼、更自然。

## Python 构建 DSL 的 5 大技巧

1. **装饰器** → `@rule` 声明式语法
2. **上下文管理器** → `with` 语句定义作用域
3. **链式调用** → 方法返回 `self` 实现流畅接口
4. **动态属性** → `__getattr__` 实现魔法访问
5. **运算符重载** → `__or__` 等实现符号 DSL

## 关键设计模式

- **Builder 模式**：分步构建复杂对象
- **Fluent Interface**：链式调用，代码像自然语言
- **Interpreter 模式**：解释执行 DSL 语句
- **Visitor 模式**：遍历 DSL 抽象语法树

## 实战收获

- 配置 DSL：属性代理 + 类型验证 + 默认值
- 规则引擎：装饰器 + 链式调用 + 优先级
- SQL 构建器：动态属性 + 链式调用

## 注意事项

- DSL 的「最小惊讶原则」：行为要符合直觉
- 过度「魔法化」会让代码难以调试
- 平衡表达力与可维护性
- 为团队成员提供充分的文档
