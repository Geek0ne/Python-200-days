# Day 109 — 性能对比分析

## 决策树 vs 随机森林 — 何时用哪个？

### 训练速度对比

```
数据集: 10,000 样本, 20 特征

┌──────────────────┬────────────┬────────────┬──────────┐
│ 模型             │ 训练时间   │ 预测时间   │ 内存占用 │
├──────────────────┼────────────┼────────────┼──────────┤
│ 决策树           │ ~0.01s     │ ~0.001s    │ ~1MB     │
│ 随机森林(100树)  │ ~0.5s      │ ~0.05s     │ ~50MB    │
│ 随机森林(300树)  │ ~1.5s      │ ~0.15s     │ ~150MB   │
│ 随机森林(1000树) │ ~5s        │ ~0.5s      │ ~500MB   │
└──────────────────┴────────────┴────────────┴──────────┘

💡 随机森林训练时间 ≈ n_estimators × 单棵树时间
💡 预测时间 ≈ n_estimators × 单棵树预测时间 (可并行)
```

### 精度对比（经验数据）

```
典型表现 (F1 分数, 二分类):

数据集           │ 决策树  │ 随机森林 │ 提升
─────────────────┼─────────┼──────────┼──────
鸢尾花 (小数据)  │ 0.93    │ 0.96     │ +3%
乳腺癌 (中数据)  │ 0.92    │ 0.97     │ +5%
信用卡 (大数据)  │ 0.78    │ 0.89     │ +11%
文本分类 (高维)  │ 0.65    │ 0.82     │ +17%

💡 数据越复杂、维度越高，随机森林优势越明显
💡 数据简单时，单棵决策树可能就够了
```

### 过拟合能力对比

```
训练集 vs 测试集准确率差距:

                    训练集    测试集    差距(过拟合)
决策树(depth=3)     0.95      0.93      0.02 ✅
决策树(depth=10)    0.99      0.88      0.11 ⚠️
决策树(depth=无)    1.00      0.82      0.18 ❌
随机森林(100树)     0.98      0.96      0.02 ✅
随机森林(300树)     0.99      0.97      0.02 ✅

💡 随机森林几乎不会过拟合（树越多越稳定）
💡 单棵决策树必须限制深度才能避免过拟合
```

### 何时选择哪个？

```
场景                          推荐
───────────────────────────── ──────────
需要向领导解释模型             决策树
快速原型验证                   决策树
数据量 < 500                   决策树
追求最高精度                   随机森林
数据有噪声                     随机森林
特征维度高                     随机森林
需要稳定性（多次运行结果一致）  随机森林
实时预测（毫秒级延迟要求）      决策树
```

### 与更高级算法的对比

```
算法              │ 优势                  │ 劣势
──────────────────┼───────────────────────┼─────────────────
决策树            │ 可解释、快、不需缩放  │ 过拟合、不稳定
随机森林          │ 稳定、准确、不易过拟合│ 黑箱、慢、内存大
GBDT/XGBoost     │ 最准确、灵活           │ 需调参、易过拟合
LightGBM         │ 大数据快、准确         │ 需调参、安装复杂
SVM              │ 小数据好、核技巧       │ 大数据慢、难解释
KNN              │ 简单直观               │ 慢、维度灾难
```
