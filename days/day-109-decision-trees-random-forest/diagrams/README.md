## 3. Bagging 采样概率

```
单个样本在 N 次 Bootstrap 中被选中的概率:

不被选中的概率 = (1 - 1/N)^N

当 N → ∞:
  (1 - 1/N)^N → 1/e ≈ 0.368

所以:
  约 63.2% 的样本会被选中 (in-bag)
  约 36.8% 的样本不会被选中 (out-of-bag, OOB)

┌─────────────────────────────────────────┐
│  N=10   → 不被选中: 34.9%               │
│  N=100  → 不被选中: 36.6%               │
│  N=1000 → 不被选中: 36.8%               │
│  N=∞    → 不被选中: 36.8% (= 1/e)       │
└─────────────────────────────────────────┘
```

## 4. 信息增益 vs 基尼系数图解

```
二分类问题: p = 正类比例

信息熵 H(p):           基尼系数 G(p):
    1.0 ┤                 0.5 ┤
        │╲                    │╲
    0.8 ┤  ╲              0.4 ┤  ╲
        │    ╲                │    ╲
    0.6 ┤     ╲           0.3 ┤     ╲
        │      ╲              │      ╲
    0.4 ┤       ╲         0.2 ┤       ╲
        │        ╲            │        ╲
    0.2 ┤         ╲       0.1 ┤         ╲
        │          ╲          │          ╲
    0.0 ┼───────────╲───  0.0 ┼───────────╲───
        0    0.5    1         0    0.5    1
           p (正类比例)          p (正类比例)

H(p) = -p·log₂(p) - (1-p)·log₂(1-p)
G(p) = 1 - p² - (1-p)² = 2p(1-p)

两者形状相似，差异不大:
  - p=0.5 时: H=1.0, G=0.5 (最大混乱度)
  - p=0 或 1 时: H=0, G=0 (完全纯净)
```

## 5. 特征重要性评估方法

```
┌──────────────────────────────────────────────────┐
│           MDI (不纯度减少) vs Permutation         │
├──────────────────────────────────────────────────┤
│                                                  │
│  MDI:                                            │
│  ┌──────────────────────────┐                    │
│  │ 每次分裂时计算:          │                    │
│  │ 不纯度减少 = P(左)×H(左) │                    │
│  │           + P(右)×H(右)  │                    │
│  │           - H(父)        │                    │
│  │                          │                    │
│  │ 累加所有用该特征的分裂   │                    │
│  └──────────────────────────┘                    │
│                                                  │
│  Permutation:                                    │
│  ┌──────────────────────────┐                    │
│  │ 1. 用测试集评估基线性能  │                    │
│  │ 2. 随机打乱特征 X 的值   │                    │
│  │ 3. 重新评估性能          │                    │
│  │ 4. 重要性 = 性能下降幅度 │                    │
│  │                          │                    │
│  │ 重复 N 次取平均          │                    │
│  └──────────────────────────┘                    │
│                                                  │
│  ⚠️ MDI 偏向高基数特征                           │
│  ✅ Permutation 更客观但更慢                      │
└──────────────────────────────────────────────────┘
```
