│  │  ┌─────────────────────────────────────────────┐    │   │
│  │  │           HTTPAdapter (连接适配器)           │    │   │
│  │  │                                             │    │   │
│  │  │  ┌──────────────────────────────────────┐  │    │   │

│  │  │  │                                      │  │    │   │

│  │  │  │  │Conn 1│ │Conn 2│ │Conn 3│  ...     │  │    │   │
│  │  │  │  │  ✅  │ │  ✅  │ │  ✅  │         │  │    │   │
│  │  │  │  └──┬───┘ └──┬───┘ └──┬───┘         │  │    │   │
│  │  │  │     │        │        │              │  │    │   │
│  │  │  └─────┼────────┼────────┼──────────────┘  │    │   │
│  │  └────────┼────────┼────────┼─────────────────┘    │   │

│              │        │        │                           │
│              ▼        ▼        ▼                           │
│  ┌──────────────────────────────────────────────────────┐  │
│  │              目标服务器                                │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                              │
│  工作流程:                                                    │

│                                                              │

## 4. Mermaid 流程图

```mermaid
graph TD
    A[创建 Session] --> B[配置请求头]
    B --> C[设置认证信息]
    C --> D[配置重试策略]

    D --> E{发送请求}
    E -->|成功| F[返回响应]
    E -->|失败| G{检查重试}

    G -->|在重试列表中| H{重试次数?}
    G -->|不在列表中| I[抛出异常]

    H -->|未达上限| J[计算退避时间]
    H -->|已达上限| I

    J --> K[等待退避时间]
    K --> E

    F --> L{检查状态码}
    L -->|成功 2xx| M[返回结果]
    L -->|重试状态码| G
    L -->|其他错误| N[抛出 HTTPError]

    M --> O[更新 Cookie]
    O --> P[返回最终响应]
```
