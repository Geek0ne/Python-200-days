# Day 119 图解 — 大模型 API 调用

## 一、API 调用全流程

```mermaid
sequenceDiagram
    participant User as 👤 用户
    participant App as 📱 你的应用
    participant API as ☁️ LLM API
    participant Tool as 🔧 外部工具

    User->>App: 输入问题
    App->>API: POST /chat/completions<br/>(messages + tools)
    
    alt 普通回复
        API-->>App: choices[0].message.content
        App-->>User: 显示回复
    else Function Calling
        API-->>App: tool_calls: [{name, args}]
        App->>Tool: 执行函数(name, args)
        Tool-->>App: 返回结果
        App->>API: 发送 tool 结果
        API-->>App: 最终回复
        App-->>User: 显示回复
    end
```

## 六、错误处理与重试策略

```mermaid
graph TD
    A[发起 API 请求] --> B{请求成功?}
    B -->|是| C[返回结果]
    B -->|否| D{错误类型?}
    
    D -->|429 Rate Limit| E[指数退避重试<br/>1s → 2s → 4s → 8s]
    D -->|5xx 服务器错误| F[等待后重试<br/>最多3次]
    D -->|400 参数错误| G[检查参数<br/>修复后重试]
    D -->|网络错误| H[检查网络<br/>稍后重试]
    
    E --> I{重试次数 < 5?}
    F --> I
    I -->|是| A
    I -->|否| J[抛出异常<br/>记录日志]
    
    style C fill:#e8f5e9
    style J fill:#ffebee
```
