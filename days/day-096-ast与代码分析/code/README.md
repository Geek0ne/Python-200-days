# Day 096 — 代码示例目录

本目录包含 AST 与代码分析的 3 个独立代码示例：

| 文件 | 内容 | 难度 |
|------|------|------|
| 01-ast基础操作.py | ast.parse/dump/unparse、NodeVisitor 遍历 | ⭐ 基础 |
| 02-ast变换与分析.py | NodeTransformer 变换、复杂度分析、作用域分析 | ⭐⭐ 进阶 |
| 03-实战自定义Linter.py | 完整的代码检查工具实现 | ⭐⭐⭐ 实战 |

## 运行方式

```bash
cd ~/code/Learn-Python
python3 days/day-096-ast与代码分析/code/01-ast基础操作.py
python3 days/day-096-ast与代码分析/code/02-ast变换与分析.py
python3 days/day-096-ast与代码分析/code/03-实战自定义Linter.py
```

所有代码均可直接运行，无需安装额外依赖。
