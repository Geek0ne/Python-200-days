## 翻车日志（按发生时间）

1. **06:14** `OverflowError: Python int too large to convert to SQLite INTEGER`
   → SQLite INTEGER 有符号，SimHash 无符号 → 加 `hash_to_signed/signed_to_hash` 并测 5 个边界。
2. **06:22** 去重把 80.6% 页面判为重复
   → 整页文本参与哈希 → 改为只取 `<article>`；仍 89.2% → 生成器正文模板复用 →
   改随机片段 + 唯一 SKU → 11.6%。副产品：TEXT_TOO_SHORT 从 0 涨到 291（空壳页现形，正确结果）。
3. **06:26** 纯 Jaccard precision 0.006
   → 抽 2 万对无关文档，Jaccard 中位 0.55 → 是语料模板太少，不是算法错 →
   片段池从 6 条扩到 40 条，中位降到 0.13。
4. **06:30** `lbfgs failed to converge after 1000 iterations`
   → 未标准化 → Pipeline(StandardScaler) + `warnings.simplefilter("error")`。
5. **06:31** 自检 `索引命中自身` 失败 → `query` 用哈希值去重，同哈希的不同文档互相覆盖 →
   改为按 payload 去重，并加"同哈希不同文档不互相覆盖"用例。
