## 6. 告警级别说明

```
┌─────────────────────────────────────────────────────────────┐
│                    告警严重级别                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🔵 INFO (信息)                                             │
│  ├─ 用途: 记录正常事件                                      │
│  ├─ 示例: 服务启动、配置变更                                │
│  └─ 处理: 仅记录日志                                        │
│                                                             │
│  ⚠️ WARNING (警告)                                          │
│  ├─ 用途: 提示潜在问题                                      │
│  ├─ 示例: CPU > 80%, 内存 > 85%                            │
│  └─ 处理: 关注，可能需要干预                                │
│                                                             │
│  🚨 CRITICAL (严重)                                         │
│  ├─ 用途: 紧急问题                                          │
│  ├─ 示例: CPU > 95%, 磁盘 > 95%, 服务宕机                  │
│  └─ 处理: 立即处理，可能导致服务中断                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
