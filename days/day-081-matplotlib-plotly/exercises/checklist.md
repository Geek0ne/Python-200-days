## 📝 基础练习题

### 练习 1：多图表绘制
用 Matplotlib 生成以下数据的可视化：
```python
x = range(1, 11)
y1 = [i**2 for i in x]      # 平方
y2 = [i**3 for i in x]      # 立方
```
要求：
- 用一条代码同时绘制两条曲线
- 添加图例、标题、坐标轴标签
- 设置网格线
- 保存为 `exercise_1.png`

### 练习 2：柱状图美化
创建一个柱状图，展示5个学生的成绩：
```python
students = ['Alice', 'Bob', 'Charlie', 'Diana', 'Eve']
scores = [85, 92, 78, 95, 88]
```
要求：
- 每个柱子用不同颜色
- 在柱子上方显示具体分数
- 成绩低于80的用红色高亮
- 设置合理的 y 轴范围

### 练习 3：子图布局
用 `plt.subplots(2, 2)` 创建 2×2 子图：
- 左上：绘制 `sin(x)` 曲线
- 右上：绘制 `cos(x)` 曲线
- 左下：绘制 `tan(x)` 曲线（注意截断 y 轴范围）
- 右下：绘制 `x^2` 抛物线
