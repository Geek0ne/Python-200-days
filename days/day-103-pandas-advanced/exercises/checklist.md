## 练习题

### 基础题

**练习 1：数据清洗**

给定以下包含各种问题的数据：
```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '姓名': ['张三', '李四', '张三', None, '赵六', '李四', '钱七'],
    '部门': ['技术', '产品', '技术', '设计', None, '产品', '运营'],
    '薪资': [18000, 22000, 18000, 16000, 25000, np.nan, 15000],
    '入职日期': ['2020-01-15', '2019-03-20', '2020-01-15', '2021-06-15', 
                '2018-11-01', '2019-03-20', '2022-08-10']
})
```
完成：
1. 检测并处理缺失值
2. 删除重复行
3. 转换数据类型
4. 输出清洗后的完整数据

**练习 2：分组聚合**

使用以下数据：
```python
df = pd.DataFrame({
    '班级': ['A', 'A', 'B', 'B', 'A', 'B', 'A', 'B'],
    '学生': ['张三', '李四', '王五', '赵六', '钱七', '孙八', '周九', '吴十'],
    '数学': [85, 92, 78, 88, 95, 72, 82, 90],
    '英语': [78, 85, 92, 75, 88, 80, 75, 95]
})
```
计算：
1. 每个班级的平均分
2. 每个学生的总分
3. 每个班级中数学最高分的学生
4. 用 transform 给每个学生添加"班级排名"列
