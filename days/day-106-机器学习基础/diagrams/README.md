## 3. 混淆矩阵图解

```
                          预 测 值
                ┌────────────┬────────────┐
                │   预测为正   │   预测为负   │
    ┌───────────┼────────────┼────────────┤
实  │  实际为正  │    TP ✅    │    FN ❌    │
际  │           │  真正例     │  假负例     │
值  │           │  (正确预测)  │  (漏报)     │
    ├───────────┼────────────┼────────────┤
    │  实际为负  │    FP ❌    │    TN ✅    │
    │           │  假正例     │  真负例     │
    │           │  (误报)     │  (正确预测)  │
    └───────────┴────────────┴────────────┘

指标关系：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  准确率 = (TP + TN) / (TP + TN + FP + FN)   ← "猜对了多少"
  精确率 = TP / (TP + FP)                      ← "猜正的对不对"
  召回率 = TP / (TP + FN)                      ← "正的被找到没"
  F1    = 2 × 精确率 × 召回率 / (精确率 + 召回率)  ← 综合
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 5. Scikit-learn API 统一模式

```
  所有 sklearn 模型都遵循相同的 3 步 API：

  ┌─────────────────────────────────────────────────┐
  │                                                   │
  │   Step 1: model = XxxModel(hyperparams)          │
  │           创建模型对象                              │
  │                                                   │
  │   Step 2: model.fit(X_train, y_train)            │
  │           用训练数据拟合模型                         │
  │           ↓                                       │
  │           模型内部学习参数                          │
  │                                                   │
  │   Step 3: y_pred = model.predict(X_test)         │
  │           用新数据预测                              │
  │           ↓                                       │
  │           输出预测结果                              │
  │                                                   │
  │   附加: score = model.score(X_test, y_test)      │
  │         计算评估指标                               │
  │                                                   │
  └─────────────────────────────────────────────────┘

  记忆口诀：创建 → 拟合(fit) → 预测(predict) → 评估(score)
```
