## 3. 向量检索原理

```
查询向量                    向量空间
    │                    (高维空间中的点)
    │                         │
    ▼                         ▼
┌─────────┐            ┌──────────────────┐
│ "装饰器" │            │                  │
│ embedding│──→         │    ● v1(装饰器)   │  ← 最近
│ [0.2,    │    距离     │                  │     距离
│  -0.4,   │←──计算──→ │  ● v3(迭代器)    │  ← 中等
│  0.6,    │            │                  │
│  ...]    │            │            ● v2  │  ← 远
└─────────┘            │           (猫)   │
                       └──────────────────┘
                       
距离度量: 余弦相似度 / 欧氏距离 / 内积
```

## 4. 文档分割策略

```
原始文档（1000 字符）:
┌──────────────────────────────────────────────────────────────┐
│ Python 装饰器是一种设计模式...装饰器本质上是一个高阶函数...  │
│ Python 生成器使用 yield 关键字...生成器的优势在于惰性求值...  │
│ Python 上下文管理器通过 __enter__ 和 __right__ 方法...       │
└──────────────────────────────────────────────────────────────┘

chunk_size=300, chunk_overlap=50 分割后:

┌─────────────────────────┐
│ chunk 1: 装饰器相关      │
│ (300字符)                │
└──────────┬──────────────┘
           │ 重叠 50 字符
┌──────────▼──────────────┐
│ chunk 2: 生成器相关      │
│ (300字符)                │
└──────────┬──────────────┘
           │ 重叠 50 字符
┌──────────▼──────────────┐
│ chunk 3: 上下文管理器    │
│ (300字符)                │
└─────────────────────────┘
```
