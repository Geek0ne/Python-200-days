# Day 097 - 代码示例目录

本目录包含领域特定语言（DSL）的 3 个实战代码示例。

## 文件说明

| 文件 | 内容 | 难度 |
|------|------|------|
| `01-装饰器与上下文管理器DSL.py` | 基础 DSL 技巧：装饰器、上下文管理器、动态属性、链式调用 | ⭐ |
| `02-规则引擎DSL.py` | 进阶 DSL：完整的规则引擎，支持优先级、装饰器和链式调用两种风格 | ⭐⭐ |
| `03-配置DSL实战.py` | 实战 DSL：嵌套配置、类型验证、默认值、JSON 导出 | ⭐⭐⭐ |

## 运行方式

```bash
cd days/day-097-领域特定语言DSL/code

# 运行基础示例
python3 01-装饰器与上下文管理器DSL.py

# 运行规则引擎示例
python3 02-规则引擎DSL.py

# 运行配置 DSL 示例
python3 03-配置DSL实战.py
```

## 学习建议

1. 先运行 `01` 理解基础技巧
2. 再看 `02` 学习如何组合技巧构建完整 DSL
3. 最后看 `03` 理解实战中的 DSL 设计
