## 2. User-Based CF 工作流程

```
                    User-Based 协同过滤
                    
    ┌─────────────────────────────────────────────┐
    │  Step 1: 构建用户-物品评分矩阵              │
    │                                             │
    │           物品1  物品2  物品3  物品4        │
    │  用户A      5      3      4      ?         │
    │  用户B      3      1      2      3         │
    │  用户C      4      3      4      3         │
    │  用户D      1      5      5      2         │
    └──────────────────────┬──────────────────────┘
                           │
                           ▼
    ┌─────────────────────────────────────────────┐
    │  Step 2: 计算用户相似度                      │
    │                                             │
    │  用户A 与 用户C 相似度最高 (都喜欢物品1,3)  │
    │                                             │
    │  sim(A,B)=0.2  sim(A,C)=0.9  sim(A,D)=0.1  │
    └──────────────────────┬──────────────────────┘
                           │
                           ▼
    ┌─────────────────────────────────────────────┐
    │  Step 3: 用邻居评分预测                      │
    │                                             │
    │  预测 A 对 物品4 的评分:                     │
    │  = r̄_A + Σ sim(A,v)×(r_v4 - r̄_v) / Σ|sim| │
    │  = 4.0 + (0.9×3 + 0.2×3) / (0.9+0.2)      │
    │  = 4.0 + 2.7/1.1 ≈ 6.45 → 归一化到 5       │
    └──────────────────────┬──────────────────────┘
                           │
                           ▼
    ┌─────────────────────────────────────────────┐
    │  Step 4: 生成推荐列表                       │
    │                                             │
    │  用户A 的推荐: 物品4(4.5), 物品5(3.8)      │
    └─────────────────────────────────────────────┘
```

## 3. 矩阵分解原理

```
         评分矩阵 R              分解为两个低维矩阵
        
    ┌─────────────────┐       ┌──────┐   ┌──────┐
    │ 5  4  0  0  1  3│       │ p11  │   │ q11  │
    │ 0  5  4  4  0  0│       │ p21  │   │ q21  │
    │ 4  0  5  3  2  0│  ≈    │ p31  │ × │ q31  │ᵀ
    │ 3  0  0  5  4  2│       │ p41  │   │ q41  │
    │ 0  3  0  0  5  4│       │ p51  │   │ q51  │
    │  (m × n)        │       └──────┘   └──────┘
    └─────────────────┘        (m × k)    (k × n)
    
    k << min(m, n)  →  降维 + 填补缺失值
    
    预测评分: r̂ᵤᵢ = pᵤ · qᵢ = Σ_k pᵤₖ × qᵢₖ
```

## 4. ALS 交替优化过程

```
    ALS (交替最小二乘法) 优化流程
    
    初始化: 随机 P, Q
         │
         ▼
    ┌────────────┐     ┌────────────┐
    │ 固定 Q     │────▶│ 优化 P     │
    │ 用闭式解   │     │ (每个用户  │
    │ 求解 P     │     │  独立求解) │
    └────────────┘     └─────┬──────┘
                             │
                             ▼
                    ┌────────────┐     ┌────────────┐
                    │ 固定 P     │────▶│ 优化 Q     │
                    │ 用闭式解   │     │ (每个物品  │
                    │ 求解 Q     │     │  独立求解) │
                    └────────────┘     └─────┬──────┘
                             ▲               │
                             │               ▼
                    ┌────────┴───────┐  ┌──────────┐
                    │ 检查是否收敛   │◀─│ 计算 RMSE│
                    │ (RMSE变化 < ε)│  │          │
                    └────────┬───────┘  └──────────┘
                             │
                    未收敛? ──┤── 是 ──▶ 继续交替
                             │
                             否
                             ▼
                        输出 P, Q
```
