## 读者练习（需自行完成，不能把生成教材当作学会）

- [ ] 用自己的正常文档建立十条带人工标签的数据，记录误报；不要制作后门样本。
- [ ] 解释命中解码函数名为什么不能判定恶意；补充“注释命中”的测试。
- [ ] 检查单文件上限、编码错误和符号链接被跳过时 JSON 与退出码的区别。
- [ ] 将合成事件分配给不同主机和不同进程启动身份，确认不能错误关联。
- [ ] 设计时间窗口边界测试，明确时间缺失/时区不明的数据如何处理。
- [ ] 用已标注数据计算 precision/recall，说明无阳性样本时指标如何报告。
- [ ] 写出证据保全、人工复核、响应审批、修复复测的步骤。
