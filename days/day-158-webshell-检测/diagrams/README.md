# Day 158 — 检测与复核流程

```mermaid
flowchart TD
    A[自己的稳定离线副本] --> B[只读遍历和资源限制]
    B --> C{可安全读取为文本?}
    C -->|否| D[记录跳过或错误 覆盖不全]
    C -->|是| E[词法规则匹配]
    E --> F[规则名 行号 相对路径]
    F --> G[人工核对业务基线]
    H[同一时间窗口的合成审计事件] --> I[按主机和进程启动身份分组]
    I --> G
    G --> J[保全证据 按事件响应流程处理]
```

不能从“命中”直接连到“删除”；不能从“没有命中”直接连到“安全”。

## 两类证据

```text
静态：文件中的 API 名称 → 只能说明存在该词法线索
行为：文件写入 + 子进程 → 需同主机、同进程实例、同时间窗
                                   ↓
                      结合基线进行人工审阅
```

进程 PID 会复用；只有 PID 相同不足以关联两个事件。教程、注释也可能包含危险 API 的名称，需控制误报。
