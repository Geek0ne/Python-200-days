# Day 141 — 爬虫监控与告警 · 图解

## 1. 监控告警整体架构（Mermaid）

```mermaid
graph TD
    A[爬虫主进程] -->|每30s写心跳| B[(Redis / heartbeat 文件)]
    A -->|运行统计| C[(数据库 / 日志)]
    B --> D[监控进程 · 独立部署]
    C --> D
    D -->|心跳超时| E[告警网关 · 分级+抑制]
    D -->|数据量骤降| E
    D -->|错误率飙升| E
    E --> F[钉钉机器人 · 加签]
    E --> G[企微机器人]
    E --> H[邮件 / 短信]
```

## 2. 指数退避 + 抖动（ASCII）

```
失败 ──等1~1.5s──▶ 重试#1 失败 ──等2~3s──▶ 重试#2 失败
      ──等4~6s──▶ 重试#3 失败 ──等8~12s──▶ 重试#4 ──▶ 成功 or 死信队列

单爬虫:  ▁▄▁▁▄▁▁▄▁        （间隔指数拉长，给服务喘息时间）
多爬虫:  ▂▁▃▁▂▁▄▁▃▁▂      （jitter 抖散，避免惊群）
```
