一、整数（int）

1.1 概念解释

Python 的 int 是任意精度整数（arbitrary-precision integer），理论上只受内存限制。这与 C/Java 等语言的固定位数整数完全不同。

python
# Python 整数可以无限大（仅受内存限制）
small = 42
huge = 10 ** 100  # 1 后面 100 个零，也能精确表示
print(huge)

1.2 原理解析：CPython 中的 int 对象

CPython 中的 int 并非 CPU 寄存器中的原生整数，而是一个堆分配的对象：

  PyObject_HEAD (16 bytes)
  ┌────────────────────┐
  │ ob_refcnt = 1       │ ← 引用计数
  │ ob_type = &PyLong_Type │ ← 类型指针
  ├────────────────────┤
  │ ob_digit[]           │ ← 实际数值，以 2^30 为基的"数字数组"
  │ [d0, d1, d2, ...]    │
  └────────────────────┘

小整数缓存：CPython 会预创建 [-5, 256] 范围内的整数对象并复用。

python
a = 256
b = 256
print(a is b)   # True — 小整数缓存

c = 257
d = 257
print(c is d)   # False — 超出缓存范围，每次新建对象

为什么设计为任意精度？
1. 避免溢出错误：C 语言中 INT_MAX + 1 产生未定义行为，Python 不会
2. 简化心智模型：不需要关心 int/long/short 的区别
3. 代价：大整数运算比原生整数慢，因为需要软件实现

二进制 0b / 0B 0b1010 10
八进制 0o / 0O 0o12 10
十进制 无 10 10
十六进制 0x / 0X 0xA 10

# 转换函数

二、浮点数（float）

2.1 概念解释

float 实现为 C 语言的 double（双精度浮点数），遵循 IEEE 754 标准。它用 64 位表示一个数：1 位符号、11 位指数、52 位尾数。

2.2 原理解析：浮点数的二进制表示

符号位  指数位 (偏移 1023)    尾数位
  ↓        ↓                    ↓
 ┌─┬──────────┬────────────────────────────────────────────────────┐
 │0│01111111111│1001001000011111101101010100010001000010110100011000│
 └─┴──────────┴────────────────────────────────────────────────────┘
  ±        × 2^(e-1023)          × (1 + f/2^52)

精度问题：某些十进制小数无法用二进制精确表示，这是所有使用 IEEE 754 的语言都有的问题。

python
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False

# 为什么？因为 0.1 在二进制中是无限循环小数
# 0.1(十进制) = 0.00011001100110011...(二进制循环)

如何看待精度问题？
1. 不是 bug，是特性：二进制与十进制之间的先天矛盾
2. 容忍误差：用 abs(a - b) < 1e-9 代替 a == b
3. 需要精确计算时：使用 decimal.Decimal

python
# 正确的浮点数比较方式
def float_equal(a, b, epsilon=1e-9):
    return abs(a - b) < epsilon

print(float_equal(0.1 + 0.2, 0.3))  # True

三、复数（complex）

3.1 概念解释

复数由实部和虚部构成，形式为 a + bj（其中 j 代表虚数单位，注意 Python 用 j 而非数学中的 i）。

python
z = 3 + 4j
print(type(z))                  # <class 'complex'>
print(z.real)                   # 3.0 — 实部
print(z.imag)                   # 4.0 — 虚部
print(z.conjugate())            # (3-4j) — 共轭复数

3.2 原理解析：为何需要复数？

复数在以下领域不可或缺：
- 信号处理：傅里叶变换的输出是复数
- 量子力学：波函数本质上是复数的
- 电路分析：阻抗用复数表示
- 计算机图形学：复数平面变换

python
import cmath  # complex math

# 欧拉公式：e^(iπ) + 1 = 0
result = cmath.exp(complex(0, math.pi))
print(result)               # (-1+1.2246467991473532e-16j) ≈ -1
print(abs(result + 1) < 1e-15)  # True — 验证欧拉恒等式

# 相位和模长
z = 3 + 4j
print(abs(z))               # 5.0 — 模长 |z| = √(3²+4²)
print(cmath.phase(z))       # 0.927... — 辐角 arctan(4/3)

3.3 复数运算

python
a = 1 + 2j
b = 3 - 1j

print(a + b)    # (4+1j)
print(a * b)    # (5+5j) — 交叉相乘
print(a / b)    # (0.1+0.7j)
print(a**2)     # (-3+4j)

# 注意：复数不支持 < > 比较
# 3 + 4j > 1 + 2j  # TypeError

四、运算符优先级与结合性

4.1 优先级全表（从高到低）

优先级 运算符 说明 结合性
1 (...) 括号 —
2 ** 幂运算 右结合
3 +x, -x, ~x 一元运算符 右结合
4 *, /, //, % 乘、除、整除、取余 左结合
5 +, - 加、减 左结合
6 <<, >> 位左移、位右移 左结合
7 & 位与 左结合
8 ^ 位异或 左结合
9 \| 位或 左结合
10 ==, !=, <, >, <=, >=, is, in 比较 左结合
11 not 逻辑非 右结合
12 and 逻辑与 左结合
13 or 逻辑或 左结合
14 if-else 三元表达式 右结合
15 := 海象运算符 右结合

4.2 原理解析：为什么**是右结合？

数学中，幂运算是右结合的：

2 ** 3 ** 2  → 2 ** (3 ** 2) → 2 ** 9 → 512
          非 (2 ** 3) ** 2 → 8 ** 2 → 64

这种设计符合数学约定：$a^{b^c} = a^{(b^c)}$

python
print(2 ** 3 ** 2)     # 512 — 右结合
print(2 ** (3 ** 2))   # 512 — 显式括号一致
print((2 ** 3) ** 2)   # 64 — 显式括号改变含义

# 小心链式赋值也是右结合
a = b = c = 42
# 等价于: a = (b = (c = 42))

4.3 常见陷阱

python
# 陷阱 1：算术和比较运算符
# 有人以为这样写是 (x + y) > z
x, y, z = 1, 2, 5
print(x + y > z)        # False — 实际上正确，因为 + 优先级高于 >

# 陷阱 2：链式比较
print(1 < 2 < 3)        # True — 等价于 1 < 2 and 2 < 3
print(1 < 3 > 2)        # True — 也合法：1 < 3 and 3 > 2

# 陷阱 3：and/or 优先级
# False or True and False → False or (True and False) → False or False → False
print(False or True and False)  # False
# 如果误解为 (False or True) and False → True and False → False（结果凑巧相同）
# 但下面就有区别了：
print(True or True and False)   # True — 等价于 True or (True and False)

# 陷阱 4：赋值与比较
# if x = 5:  ← Python 中禁止，不会把赋值当条件
# but:
if n := len("hello"):   # 海象运算符可以在表达式中赋值
    print(f"长度是 {n}")  # 长度是 5

五、位运算原理

5.1 概念解释

位运算直接操作整数的二进制位，是最底层的运算形式。Python 的 int 虽然是任意精度，但位运算符对每一位进行独立操作。

5.2 运算符总览

运算符 名称 示例 说明
& 位与 (AND) 5 & 3 → 1 两个位都为 1 时结果为 1
\| 位或 (OR) 5 \| 3 → 7 至少一个位为 1 时结果为 1
^ 位异或 (XOR) 5 ^ 3 → 6 两个位不同时结果为 1
~ 位非 (NOT) ~5 → -6 按位取反（含符号位）
<< 左移 5 << 1 → 10 左移 n 位等价于 × 2ⁿ
>> 右移 5 >> 1 → 2 右移 n 位等价于 ÷ 2ⁿ（向下取整）

5.3 原理解析：补码表示

Python 中的整数使用补码（two's complement）表示，理论上无限位：

二进制                                 十进制
  ...00000101                          5
  ...00000011                          3
& ...00000001                          1
────────────────────────────────────
  ...00000101                          5
| ...00000011                          3
  ...00000111                          7
────────────────────────────────────
  ...00000101                          5
^ ...00000011                          3
  ...00000110                          6
────────────────────────────────────
  ~...00000101
  ...11111010                          -6  ← 取反后加 -1 等于 -6

为什么 ~5 = -6？
因为 Python 的整数位数无限，~5 翻转所有位：
- 5 的无限补码：...00000101
- 取反后：...11111010
- 这个值是 -6（-6 的补码正是 ...11111010）

5.4 位运算实战技巧

python
# 1. 检查奇偶性（比 % 2 更快）
def is_odd(n):
    return n & 1 == 1

print(is_odd(5))   # True
print(is_odd(6))   # False

# 2. 交换变量（不使用第三个变量）
a, b = 5, 3
a ^= b  # a = a ^ b
b ^= a  # b = b ^ a = (a ^ b) ^ b = a
a ^= b  # a = a ^ b = (a ^ b) ^ a = b
print(a, b)         # 3, 5

# 3. 判断是否为 2 的幂
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

for n in [1, 2, 4, 8, 16, 3, 6, 10]:
    print(f"{n}: {is_power_of_two(n)}")

# 4. 取最低位的 1
n = 0b101100
lowest_one = n & -n
print(bin(lowest_one))  # 0b100

# 5. 清除最低位的 1
n = 0b101100
cleared = n & (n - 1)
print(bin(cleared))     # 0b101000

# 6. 位掩码 — 用位来存储多个布尔标志
READ = 0b001
WRITE = 0b010
EXECUTE = 0b100

permissions = READ | WRITE  # 0b011 — 可读可写
can_read = permissions & READ != 0      # True
can_execute = permissions & EXECUTE != 0  # False

# 添加执行权限
permissions |= EXECUTE      # 0b111
# 移除写权限
permissions &= ~WRITE       # 0b101

5.5 位运算图解

8 的二进制表示：      00001000
8 >> 1 (右移一位)：   00000100  = 4  (等价于 ÷2)
8 << 1 (左移一位)：   00010000  = 16 (等价于 ×2)
7 >> 1 (奇数右移)：  00000011  = 3  (向下取整 ÷2)

掩码操作图解（清除 bit 2）：
  原值：     10110101
  掩码：    &11011111  (= ~00100000)
  结果：     10010101

六、类型转换（Type Conversion）

6.1 隐式类型转换（Implicit）

Python 在运算中自动将"精度较低"的类型转为"精度较高"的类型。

转换链：int → float → complex

python
# int + float → float
result = 3 + 2.5
print(type(result), result)   # <class 'float'> 5.5

# int + complex → complex
result = 3 + (1+2j)
print(type(result), result)   # <class 'complex'> (4+2j)

# bool 是 int 的子类
print(True + 1)               # 2 — True 被视为 1
print(False * 5)              # 0 — False 被视为 0
print(True + False)           # 1

6.2 显式类型转换（Explicit）

python
# int() — 转为整数
print(int(3.14))        # 3 — 截断取整（不四舍五入）
print(int("42"))        # 42
print(int("0xFF", 16))  # 255 — 指定进制
print(int(True))        # 1

# float() — 转为浮点数
print(float(3))         # 3.0
print(float("3.14"))    # 3.14
print(float("nan"))     # nan
print(float("inf"))     # inf

# complex() — 转为复数
print(complex(3))       # (3+0j)
print(complex(3, 4))    # (3+4j)
print(complex("3+4j"))  # (3+4j)

# bool() — 转为布尔值
print(bool(0))          # False
print(bool(0.0))        # False
print(bool(42))         # True
print(bool(""))         # False
print(bool("hello"))    # True

6.3 常见转换陷阱

python
# 陷阱 1：int() 对浮点数截断而非四舍五入
print(int(3.9))             # 3 — 直接砍掉小数部分
print(int(-3.9))            # -3 — 向零取整
print(round(3.5))           # 4 — round() 银行家舍入
print(round(4.5))           # 4 — 银行家舍入：偶数时舍去

# 陷阱 2：字符串转数字可能失败
try:
    value = int("3.14")     # ValueError ！
except ValueError:
    value = float("3.14")   # 先转 float 再转 int
    value = int(value)
print(value)                # 3

# 陷阱 3：布尔值参与算术
count = True + True + True
print(count)                # 3 — 可能不是你想要的结果
print(type(True))           # <class 'bool'>
print(isinstance(True, int))  # True — bool 是 int 的子类！

6.4 安全转换最佳实践

python
def safe_int(value, default=0):
    """安全地将输入转为整数，转换失败返回默认值"""
    try:
        return int(value)
    except (ValueError, TypeError):
        return default

def safe_float(value, default=0.0):
    """安全地将输入转为浮点数"""
    try:
        return float(value)
    except (ValueError, TypeError):
        return default

# 使用示例
print(safe_int("42"))           # 42
print(safe_int("not a number")) # 0
print(safe_int(None))           # 0
print(safe_float("3.14"))       # 3.14

import math

def get_number(prompt="请输入一个数: ", num_type=float):
    """安全获取数字输入"""
    while True:
        try:
            return num_type(input(prompt))
        except (ValueError, TypeError):
            print("❌ 输入无效，请重新输入。")


def get_two_numbers():
    """获取两个操作数"""
    a = get_number("第一个数: ")
    b = get_number("第二个数: ")
    return a, b


def basic_operations():
    """基础四则运算"""
    a, b = get_two_numbers()
    print(f"\n结果:")
    print(f"  {a} + {b} = {a + b}")
    print(f"  {a} - {b} = {a - b}")
    print(f"  {a} * {b} = {a * b}")
    if b != 0:
        print(f"  {a} / {b} = {a / b}")
        print(f"  {a} // {b} = {a // b}")
        print(f"  {a} % {b} = {a % b}")
    else:
        print(f"  {a} / {b} = 错误：除数不能为零")
        print(f"  {a} // {b} = 错误：除数不能为零")
        print(f"  {a} % {b} = 错误：除数不能为零")
    print(f"  {a} ** {b} = {a ** b}")


def scientific_operations():
    """科学运算"""
    choice = input("请选择 (8=平方根, 9=三角函数, 10=对数): ").strip()
    
    if choice == "8":
        n = get_number("输入数值: ")
        if n < 0:
            print(f"  √{n} = {cmath.sqrt(n)} (复数结果)")

    elif choice == "9":
        x = get_number("输入角度(度): ")
        rad = math.radians(x)
        print(f"  sin({x}°) = {math.sin(rad):.6f}")
        print(f"  cos({x}°) = {math.cos(rad):.6f}")
        print(f"  tan({x}°) = {math.tan(rad):.6f}")
    elif choice == "10":
        n = get_number("输入数值: ")
        if n <= 0:
            print("❌ 对数要求正数。")

                print(f"  log_{base}({n}) = {math.log(n, base):.6f}")
    else:
        print("❌ 无效选项。")


def bitwise_operations():

def is_prime(n: int) -> bool:
    """检查素数"""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    # 只需要检查到 √n
    limit = int(math.sqrt(n)) + 1
    for i in range(3, limit, 2):
        if n % i == 0:
            return False
    return True

        # 找到最小因子
        for i in range(2, int(math.sqrt(n)) + 1):
            if n % i == 0:

                break

💭 思考题

  1. 精度与性能：Python 的任意精度整数在什么情况下会显著慢于 C 语言的固定位数整数？写一个基准测试验证你的猜想。

参考答案

C 的固定位数整数（如 64 位）直接放在 CPU 寄存器里，一次乘法就是一条机器指令。Python 的 int 是堆上的对象：小整数（一个 30 位「数字」就能装下）运算还算快，但仍有对象分配、引用计数的开销；一旦数值大到需要多个「数字」存储，乘除、取余就得用软件模拟竖式运算（位数越多越慢），这时与 C 的差距会急剧拉大。所以大整数的乘除/取余、密码学级别的大数运算、密集循环里的大数计算是显著变慢的典型场景。

用标准库 timeit 做个对比（小整数 vs 300 位大整数）：

python
import timeit  # 标准库的计时工具

# 小整数：一个"数字"即可表示，接近原生运算
small = timeit.timeit("a * b", setup="a = 12345; b = 6789", number=1_000_000)
# 大整数：需要多个"数字"，软件模拟竖式乘法
big = timeit.timeit("a * b", setup="a = 10**300; b = 10**300", number=200_000)

print(f"小整数乘法 100 万次: {small:.3f} 秒")
print(f"大整数乘法 100 万次: {big * 5:.3f} 秒")  # 换算成同样次数
print(f"大整数约慢 {big * 5 / small:.0f} 倍")

一次实测的示例输出（具体秒数因机器而异，但量级关系稳定）：

小整数乘法 100 万次: 0.013 秒
大整数乘法 100 万次: 0.705 秒
大整数约慢 54 倍

可见同样是乘法，300 位大整数比小整数慢了几十倍——这正是「任意精度」用软件运算换来的代价。💡 提示：日常小整数运算不必担心性能；真要处理海量大数运算，可考虑 gmpy2 这类底层用 C 实现的库。

  1. 浮点数之谜：为什么 0.1 + 0.2 != 0.3，但 0.5 + 0.25 == 0.75 却没有精度问题？哪些小数在二进制中可以精确表示？

参考答案

浮点数用二进制小数存储，而只有分母是 2 的幂的分数才能用有限位二进制精确表示。0.5 = 1/2、0.25 = 1/4、0.75 = 3/4，分母都是 2 的幂，二进制分别是 0.1、0.01、0.11，有限且精确，相加自然没有误差。而 0.1 = 1/10，分母含因子 5，二进制是无限循环小数 0.000110011…，只能截断存储，于是 0.1、0.2、0.3 各自都带一点点误差，加起来就对不上了。

用 as_integer_ratio() 能看到浮点数背后真正的分数（分母必为 2 的幂）：

python
print(0.1 + 0.2 == 0.3)     # False
print(0.5 + 0.25 == 0.75)   # True
print((0.1).as_integer_ratio())   # 0.1 实际存的分数
print((0.5).as_integer_ratio())   # 0.5 精确 = 1/2
print((0.75).as_integer_ratio())  # 0.75 精确 = 3/4

预期输出：

False
True
(3602879701896397, 36028797018963968)
(1, 2)
(3, 4)

0.1 对应的分数分子分母都巨大且不相等，说明它只是个近似值；0.5、0.75 则是干净的 1/2、3/4。规律：能精确表示的小数形如 k/2ⁿ，例如 0.5、0.25、0.125、0.375、0.75；而 0.1、0.2、0.3 这类含因子 5 的都不行。💡 提示：这不是 Python 的 bug，所有 IEEE 754 语言都一样；比较小数用 abs(a-b) < 1e-9，算钱用 decimal.Decimal。

  1. 位运算威力：不用 * 和 /，仅用位运算实现一个整数乘以 10 的函数。提示：n * 10 = n * (8 + 2) = n * 8 + n * 2 = (n << 3) + (n << 1)

参考答案

核心思路：左移 k 位等价于乘 2ᵏ。把 10 拆成 8 + 2（都是 2 的幂），于是 n * 10 = n*8 + n*2 = (n << 3) + (n << 1)，全程只用移位和加法，不碰 *、/：

python
def mul10(n):
    # n * 10 = n * (8 + 2) = (n << 3) + (n << 1)
    return (n << 3) + (n << 1)

for n in [0, 1, 7, -3, 123]:
    print(n, mul10(n))

预期输出：

0 0
1 10
7 70
-3 -30
123 1230

对负数同样成立，因为 Python 的移位是算术移位，符号会正确保留。💡 提示：现代编译器/解释器通常会自动把「乘 2 的幂」优化成移位，手写位运算更多是为了理解原理或应对面试题，日常代码直接写 n * 10 更清晰。

  1. 隐式转换的风险：写出一个利用布尔值是整数子类的"bug"代码——即因为 True 被当作 1 而导致逻辑错误的场景。

参考答案

一个隐蔽又真实的坑：True == 1 且两者哈希值相同，所以拿布尔值当字典键时，会和整数键 1 撞键，悄悄覆盖数据：

python
# 用数字做键记录奖项
scores = {1: "金牌", 2: "银牌"}
scores[True] = "布尔值"   # 本意是新增一个键，但 True == 1，覆盖了键 1！
print(scores)

预期输出：

{1: '布尔值', 2: '银牌'}

键 1 的「金牌」不见了——因为字典认为 True 和 1 是同一个键。类似的坑还有：isinstance(True, int) 返回 True，让「只接受整数」的校验放行了布尔值；以及 if status == True: 在 status 为 2 时判 False，但 if status: 却为真，两种写法行为不一致。💡 提示：判断布尔就用 if flag:，判断整数类型用 type(x) is int（排除 bool），别把布尔值混进数字键的字典。

  1. 复数应用：创建一个复数类，模拟 Mandelbrot 集合的迭代计算：z = z² + c。对于初始值 c，如果迭代 100 次后 |z| < 2，则 c 属于集合。

参考答案

Python 内置的 complex 就是现成的复数类，支持 +、* 和 abs()（求模长），直接用它即可。Mandelbrot 集合的判定：从 z = 0 出发反复迭代 z = z² + c，若序列始终不发散（模长不超过 2），则 c 属于集合。

python
def in_mandelbrot(c, max_iter=100):
    z = 0j  # 从原点出发，0j 是复数零
    for _ in range(max_iter):
        z = z * z + c          # 核心迭代 z = z² + c
        if abs(z) > 2:         # 一旦模长超过 2 必然发散，提前退出
            return False
    return abs(z) < 2          # 迭代结束仍未逃逸 → 属于集合

# 测试几个点：原点、-1 在集合内；0.5+0.5j、1+1j 会逃逸
for c in [0j, -1+0j, -0.5+0.5j, 0.5+0.5j, 1+1j]:
    print(c, in_mandelbrot(c))

预期输出：

0j True
(-1+0j) True
(-0.5+0.5j) True
(0.5+0.5j) False
(1+1j) False

abs(z) > 2 就提前返回，是因为数学上可以证明：只要某一步模长超过 2，序列必定趋向无穷，不可能再回到集合内——这既符合题意，又避免了大数溢出。💡 提示：把平面上每个像素对应的 c 都跑一遍这个函数，按是否属于集合着色，就能画出著名的 Mandelbrot 分形图。
