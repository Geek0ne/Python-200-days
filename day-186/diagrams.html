1. 五层资产模型

┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  L1 根域名   │ ──▶ │  L2 子域名   │ ──▶ │   L3 IP     │
│ example.com │     │ api.xxx.com │     │ 192.0.2.10  │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                    ┌─────────────┐     ┌──────▼──────┐
                    │  L5 漏洞     │ ◀── │ L4 端口/服务 │
                    │ SQLi / XSS  │     │ 443 / https │
                    └─────────────┘     └─────────────┘

每一层只依赖上一层：没有域名就没有子域名，没有 IP 就扫不了端口。 Pipeline 的输入输出必须落盘，才能重跑和差分。

3. 泛解析为什么会骗人

正常 DNS:
  www.example.com  ──▶ 192.0.2.10
  api.example.com  ──▶ 192.0.2.11
  nope.example.com ──▶ NXDOMAIN      ✅ 可以区分

泛解析:
  *.example.com    ──▶ 192.0.2.99
  www.example.com  ──▶ 192.0.2.10
  nope.example.com ──▶ 192.0.2.99    ❌ 看起来"存在"
  x7f2k9q1.example.com ──▶ 192.0.2.99

检测思路：先问 3 个随机名字，拿到泛解析 IP 集合；枚举时把 "IP 集合完全等于泛解析集合"的结果丢掉。
