5. 描述符生命周期

sequenceDiagram participant C as Class participant D as Descriptor participant O as Object Note over C,D: 类定义时 C->>D: __set_name__(owner, name) Note over D: D 记住字段名 Note over O,D: 实例赋值时 O->>D: __set__(obj, value) D->>D: validate(value) D->>O: setattr(obj, private_name, value) Note over O,D: 实例读取时 O->>D: __get__(obj, objtype) D->>O: getattr(obj, private_name) D-->>O: 返回值 
sequenceDiagram
    participant C as Class
    participant D as Descriptor
    participant O as Object

    Note over C,D: 类定义时
    C->>D: __set_name__(owner, name)
    Note over D: D 记住字段名

    Note over O,D: 实例赋值时
    O->>D: __set__(obj, value)
    D->>D: validate(value)
    D->>O: setattr(obj, private_name, value)

    Note over O,D: 实例读取时
    O->>D: __get__(obj, objtype)
    D->>O: getattr(obj, private_name)
    D-->>O: 返回值
