3. Lambda 表达式原理

sequenceDiagram participant C as 代码: lambda x, y: x + y participant P as Python 解释器 participant O as 内存对象 C->>P: 解析 lambda 表达式 P->>P: 编译为字节码 (LOAD_FAST, BINARY_OP, RETURN_VALUE) P->>O: 创建函数对象 O-->>P: co_code, co_consts, co_freevars P-->>C: 返回函数对象 (无 __name__) 
sequenceDiagram
    participant C as 代码: lambda x, y: x + y
    participant P as Python 解释器
    participant O as 内存对象

    C->>P: 解析 lambda 表达式
    P->>P: 编译为字节码 (LOAD_FAST, BINARY_OP, RETURN_VALUE)
    P->>O: 创建函数对象
    O-->>P: co_code, co_consts, co_freevars
    P-->>C: 返回函数对象 (无 __name__)
