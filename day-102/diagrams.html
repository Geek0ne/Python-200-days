2. loc vs iloc 选择对比

DataFrame:
┌────┬────────┬───────┬────────┐
│    │  姓名   │  年龄  │  薪资  │
├────┼────────┼───────┼────────┤
│ 0  │  张三   │  25   │ 15000 │ ← loc['张三'] 或 iloc[0]
│ 1  │  李四   │  30   │ 25000 │ ← loc['李四'] 或 iloc[1]
│ 2  │  王五   │  35   │ 18000 │ ← loc['王五'] 或 iloc[2]
└────┴────────┴───────┴────────┘
       ↑              ↑
   loc['姓名']    loc['年龄']
   iloc[:, 0]     iloc[:, 1]

loc:
  df.loc[0, '姓名']     → '张三'
  df.loc[0:1, '姓名']   → 第0行到第1行的姓名（包含两端！）

iloc:
  df.iloc[0, 0]          → '张三'
  df.iloc[0:2, 0]        → 第0行到第1行的姓名（不包含结束！）

3. 布尔索引工作流程

原始 DataFrame:
┌────┬────────┬───────┐
│    │  产品   │  价格  │
├────┼────────┼───────┤
│ 0  │  手机   │ 4999  │
│ 1  │  电脑   │ 6999  │
│ 2  │  耳机   │  999  │
│ 3  │  平板   │ 3999  │
└────┴────────┴───────┘

步骤 1: 创建布尔掩码
mask = df['价格'] > 3000
┌────┬───────┐
│ 0  │ True  │   4999 > 3000 ✓
│ 1  │ True  │   6999 > 3000 ✓
│ 2  │ False │    999 > 3000 ✗
│ 3  │ True  │   3999 > 3000 ✓
└────┴───────┘

步骤 2: 用掩码筛选
df[mask]
┌────┬────────┬───────┐
│ 0  │  手机   │ 4999  │  ← True
│ 1  │  电脑   │ 6999  │  ← True
│ 3  │  平板   │ 3999  │  ← True
└────┴────────┴───────┘

多条件（注意括号优先级）:
mask = (df['价格'] > 3000) & (df['产品'] != '电脑')
       ├──── 条件1 ────┤   ├──── 条件2 ────┤

5. 文件读写格式对比

┌──────────────┬──────────┬──────────┬─────────────┐
│    格式      │  速度    │  文件大小 │  适用场景    │
├──────────────┼──────────┼──────────┼─────────────┤
│ CSV          │  慢      │  大      │  通用交换    │
