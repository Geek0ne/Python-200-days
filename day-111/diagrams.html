3. PCA 降维原理图

flowchart TD A[原始高维数据 X<br/>n × d] --> B[步骤1: 中心化<br/>减去均值] B --> C[步骤2: 计算协方差矩阵<br/>C = X^T X / (n-1)] C --> D[步骤3: 特征值分解<br/>C v_i = λ_i v_i] D --> E[步骤4: 选择主成分<br/>按特征值从大到小排列] E --> F[步骤5: 投影<br/>Z = X W_d] F --> G[输出低维数据 Z<br/>n × d', 其中 d' < d] style A fill:#e1f5fe style G fill:#c8e6c9 style D fill:#fff3e0 
flowchart TD
    A[原始高维数据 X<br/>n × d] --> B[步骤1: 中心化<br/>减去均值]
    B --> C[步骤2: 计算协方差矩阵<br/>C = X^T X / (n-1)]
    C --> D[步骤3: 特征值分解<br/>C v_i = λ_i v_i]
    D --> E[步骤4: 选择主成分<br/>按特征值从大到小排列]
    E --> F[步骤5: 投影<br/>Z = X W_d]
    F --> G[输出低维数据 Z<br/>n × d', 其中 d' < d]
    
    style A fill:#e1f5fe
    style G fill:#c8e6c9
    style D fill:#fff3e0
