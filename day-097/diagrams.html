5. DSL 设计权衡图

表达力强
    ▲
    │     ★ SQL
    │        ★ HTML
    │     ★ Jinja2
    │  ★ SQLAlchemy
    │     ★ Flask 路由
    │  ★ 本日配置 DSL
    │        ★ 规则引擎
    │
    │─────────────────────────► 可维护性高
    │
    │     ⚠️ 过度魔法化
    │        ⚠️ 隐式行为
    │           ⚠️ 调试困难
    ▼

📝 设计原则：好的 DSL 应该在表达力和可维护性之间找到平衡点。过于「魔法化」的 DSL 会让代码难以理解和调试。
