3. 向量检索原理

查询向量                    向量空间
    │                    (高维空间中的点)
    │                         │
    ▼                         ▼
┌─────────┐            ┌──────────────────┐
│ "装饰器" │            │                  │
│ embedding│──→         │    ● v1(装饰器)   │  ← 最近
│ [0.2,    │    距离     │                  │     距离
│  -0.4,   │←──计算──→ │  ● v3(迭代器)    │  ← 中等
│  0.6,    │            │                  │
│  ...]    │            │            ● v2  │  ← 远

                       └──────────────────┘
                       
距离度量: 余弦相似度 / 欧氏距离 / 内积
