2. HTTP 轮询 vs WebSocket 对比

HTTP 轮询（低效）:
─────────────────────────────────────────────
时间轴 ─────────────────────────────────────▶

客户端:  ──请求──    ──请求──    ──请求──    ──请求──
         │           │           │           │
服务器:  ──响应──    ──响应──    ──响应──    ──响应──
                    ↑ 新数据在这里产生，但客户端不知道

WebSocket（高效）:
─────────────────────────────────────────────
时间轴 ─────────────────────────────────────▶

客户端:  ═══握手═════════════════════════════════
         │
服务器:  ════════════════════════════════════════
              ↑           ↑           ↑
           推送数据     推送数据     推送数据
         (服务器主动发送，无需客户端请求)
