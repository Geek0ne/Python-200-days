Day 110 — SVM 与 KNN

两大经典分类算法：支持向量机（SVM）与 K 近邻（KNN）

📋 今日学习目标

  1. 理解 SVM 的核心思想——最大间隔分类器
  2. 掌握核技巧（Kernel Trick）的原理与应用
  3. 理解 KNN 算法的原理、K 值选择策略
  4. 对比不同分类算法的适用场景
  5. 实战：手写数字识别（SVM vs KNN）

一、SVM — 支持向量机

1.1 什么是 SVM？

SVM（Support Vector Machine，支持向量机）是一种监督学习算法，核心思想是找到一个最优超平面，使得不同类别之间的间隔（margin）最大化。

为什么选择最大间隔？
- 最大间隔意味着更好的泛化能力
- 对新数据的分类更鲁棒
- 即使数据有噪声，也能保持较好的分类效果

1.2 核心概念

超平面（Hyperplane）

在二维空间中是直线，在三维中是平面，在更高维中是超平面。

对于二分类问题，超平面方程为：

w · x + b = 0

其中：
- w 是法向量（决定超平面方向）
- b 是偏置（决定超平面位置）

间隔（Margin）

间隔是超平面到最近数据点距离的两倍：

间隔 = 2 / ||w||

最大化间隔 = 最小化 ||w||，这是一个二次规划问题。

支持向量（Support Vectors）

距离超平面最近的那些数据点，它们"支撑"着超平面的位置。只有支持向量决定了最终的分类边界。

1.3 硬间隔 vs 软间隔

硬间隔（Hard Margin）

  • 要求所有样本都严格分类正确
  • 对噪声极其敏感
  • 要求数据线性可分

软间隔（Soft Margin）

  • 允许部分样本分类错误
  • 引入松弛变量 ξ（xi）
  • 通过参数 C 控制"容忍度"：
最小化: ||w||²/2 + C * Σξᵢ
约束: yᵢ(w · xᵢ + b) ≥ 1 - ξᵢ, ξᵢ ≥ 0

C 的含义：
- C 越大 → 越不允许犯错（可能过拟合）
- C 越小 → 越容忍错误（可能欠拟合）

1.4 核技巧（Kernel Trick）

问题： 现实中的数据往往不是线性可分的。

解决方案： 将数据映射到高维空间，使其变得线性可分。

核技巧的妙处： 不需要真正计算高维映射，只需要计算核函数 K(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ)，就能得到高维空间的内积。

常用核函数

核函数 公式 特点 适用场景
线性核 K(x,y) = x·y 最简单，等价于线性SVM 线性可分数据
多项式核 K(x,y) = (γx·y + r)^d 非线性，参数多 有明确多项式特征的数据
RBF核（高斯核） K(x,y) = exp(-γ||x-y||²) 最常用，映射到无穷维 通用，效果好
Sigmoid核 K(x,y) = tanh(γx·y + r) 类似神经网络 特定场景

1.5 sklearn 中的 SVM

python
from sklearn.svm import SVC, LinearSVC, SVR

# 分类
clf = SVC(kernel='rbf', C=1.0, gamma='scale')
clf.fit(X_train, y_train)
y_pred = clf.predict(X_test)

# 线性分类（更快）
clf = LinearSVC(C=1.0, max_iter=10000)

# 回归
reg = SVR(kernel='rbf', C=1.0)

关键参数：
- kernel：核函数类型（'linear', 'rbf', 'poly', 'sigmoid'）
- C：正则化参数（越大越严格）
- gamma：RBF核的参数（越大越复杂）
- degree：多项式核的阶数

二、KNN — K 近邻

2.1 什么是 KNN？

KNN（K-Nearest Neighbors，K 近邻）是最简单的机器学习算法之一。核心思想：物以类聚——一个样本的类别由其最近的 K 个邻居的类别投票决定。

特点：
- 懒惰学习（Lazy Learning）：没有训练过程，所有计算都在预测时进行
- 非参数方法：不假设数据的分布形式
- 直观易懂：就像"近朱者赤，近墨者黑"

2.2 算法流程

1. 选择 K 值
2. 计算待预测样本与所有训练样本的距离
3. 找到距离最近的 K 个样本
4. 统计这 K 个样本的类别
5. 投票决定待预测样本的类别（多数票）

2.3 距离度量

欧氏距离（Euclidean Distance）

d(x, y) = √(Σ(xᵢ - yᵢ)²)

最常用，适用于连续特征。

曼哈顿距离（Manhattan Distance）

d(x, y) = Σ|xᵢ - yᵢ|

适用于稀疏数据或高维空间。

闵可夫斯基距离（Minkowski Distance）

d(x, y) = (Σ|xᵢ - yᵢ|^p)^(1/p)

p=1 时为曼哈顿距离，p=2 时为欧氏距离。

2.4 K 值选择

K 值是 KNN 最重要的超参数：

K 值 效果 风险
K=1 最复杂，完美拟合训练集 过拟合，对噪声敏感
K=适中 平衡偏差与方差 需要调参
K=N 最简单，总是预测多数类 欠拟合，无意义

选择策略：
1. 经验法则：K = √N（N 为样本数）
2. 交叉验证：尝试不同的 K 值，选择验证集准确率最高的
3. 奇数 K：避免平票（二分类时）

2.5 数据预处理的重要性

KNN 对特征尺度非常敏感！ 因为它基于距离计算。

2.6 sklearn 中的 KNN

python
from sklearn.neighbors import KNeighborsClassifier, KNeighborsRegressor

# 分类
clf = KNeighborsClassifier(n_neighbors=5, weights='uniform', metric='minkowski')

# 回归

关键参数：
- n_neighbors：K 值
- weights：'uniform'（等权重）或 'distance'（距离加权）
- metric：距离度量方式
- algorithm：'ball_tree', 'kd_tree', 'brute', 'auto'

三、SVM vs KNN 对比

3.1 对比总结

特性 SVM KNN
类型 判别模型 基于实例
训练 快（有训练过程） 慢（无需训练）
预测 快 慢（需计算所有距离）
内存 只需存支持向量 需存全部训练数据
可解释性 中等（支持向量） 低
高维数据 好（核技巧） 差（维度灾难）
数据量 适合大数据 小数据效果好
特征缩放 需要 必须
噪声敏感 软间隔可调 较敏感

3.2 选择建议

选 SVM 当：
- 数据维度高（如文本分类）
- 数据量大
- 需要更好的泛化能力

选 KNN 当：
- 数据量小
- 需要简单快速的基线
- 数据分布不规则

六、思考题

  1. 为什么 SVM 对高维数据效果好，而 KNN 不行？
    - 提示：考虑"维度灾难"和核技巧

参考答案

KNN 完全依赖「距离」找邻居。维度一高就会遭遇维度灾难：所有点之间的距离趋于相近（距离集中），「最近邻」失去区分意义；同时需要指数级增长的样本才能填满空间，大量噪声维度还会淹没真正有用的距离信号。于是 KNN 在高维下迅速退化。

SVM 则不同：核技巧把数据隐式映射到高维，只需计算核函数（内积），不用真的枚举邻居；最大间隔解只由少数支持向量决定，再加上正则化参数 C 控制复杂度，即使「特征数 ≫ 样本数」（如文本）也能很好泛化。

小例子：1 万维 TF-IDF 文本、样本不多——线性 SVM 表现很好；KNN 因为所有距离都差不多而几乎失效。

💡 提示：KNN 在高维下要先做特征选择/降维和标准化；SVM 选对核与 C 就能直接应对高维。

  1. SVM 中参数 C 和 gamma 分别控制什么？如何联合调参？
    - 提示：C 控制正则化，gamma 控制核函数的"影响力范围"

参考答案

  • C（正则化/容错）：C 越大，越严惩分类错误，力求把训练点都分对 → 边界复杂、易过拟合；C 越小，越容忍错误 → 间隔更宽、边界更平滑、可能欠拟合。
  • gamma（RBF 核影响范围）：gamma 越大，单个支持向量只影响很近的点 → 边界扭曲、易过拟合；gamma 越小，影响范围越远 → 边界平滑、可能欠拟合。

两者会相互作用：大 C + 大 gamma 极易过拟合，小 C + 小 gamma 易欠拟合。联合调参通常在对数刻度（0.01/0.1/1/10/100）上用网格或随机搜索 + 交叉验证一起搜。

下面在带噪声的月牙数据上实测（需 pip install scikit-learn）：

python
from sklearn.datasets import make_moons
from sklearn.svm import SVC
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# 带噪声的月牙形数据：线性不可分，适合观察 RBF 核参数影响
X, y = make_moons(n_samples=300, noise=0.25, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

print("C(容错) / gamma(核影响范围) -> 训练准确率 / 测试准确率")
for C in [0.1, 1, 100]:
    for gamma in [0.1, 1, 10]:
        clf = SVC(kernel='rbf', C=C, gamma=gamma)
        clf.fit(X_train, y_train)
        print(f"C={C:5g}, gamma={gamma:4g} -> {clf.score(X_train, y_train):.3f} / {clf.score(X_test, y_test):.3f}")

预期输出（数值因机器/版本而异）：

C(容错) / gamma(核影响范围) -> 训练准确率 / 测试准确率
C=  0.1, gamma= 0.1 -> 0.852 / 0.889
C=  0.1, gamma=   1 -> 0.905 / 0.889
C=  0.1, gamma=  10 -> 0.824 / 0.733
C=    1, gamma= 0.1 -> 0.852 / 0.900
C=    1, gamma=   1 -> 0.919 / 0.922
C=    1, gamma=  10 -> 0.952 / 0.922
C=  100, gamma= 0.1 -> 0.910 / 0.900
C=  100, gamma=   1 -> 0.943 / 0.922
C=  100, gamma=  10 -> 0.990 / 0.889

可以看到：C=100, gamma=10 训练 0.990 但测试只有 0.889（过拟合差距大）；C=1, gamma=1 训练/测试都≈0.92（较均衡）；gamma 过大或 C 过小都会掉点。

  1. KNN 的 weights='distance' 在什么情况下比 weights='uniform' 好？
    - 提示：考虑数据分布不均匀的情况

参考答案

uniform 让 K 个邻居等权投票；distance 让越近的邻居权重越大（权重∝1/距离）。

当数据分布不均匀、密度差异大时，distance 更好：在稀疏区域，凑够 K 个邻居往往要伸到很远、混进无关类别的点；距离加权会压低这些远邻居的话语权，让真正贴近的同类点主导结果。类别在边界重叠、或 K 取较大时，也能避免「远处的大类」淹没「近处的小类」。

小例子：待测点紧挨 A 类簇，但 K=10 会够到 B 类区域——uniform 下 B 数量多可能胜出；distance 下近处的 A 权重远大于远处的 B，仍判 A（正确）。

💡 提示：distance 加权对 K 的取值和密度不均更鲁棒；uniform 更简单快，数据分布均匀时也够用。

  1. 如何用 SVM 处理多分类问题？
    - 提示：One-vs-One (OvO) 和 One-vs-Rest (OvR)

参考答案

SVM 本质是二分类器，多分类靠「拆成多个二分类」：

  • OvR（One-vs-Rest，一对多）：训练 K 个分类器，每个区分「第 k 类 vs 其余所有类」，预测时取置信度最高的那类。共 K 个模型。
  • OvO（One-vs-One，一对一）：每两类之间训练一个分类器，共 K(K-1)/2 个，预测时多数投票。模型更多，但每个只用两类样本训练、规模小，常常更快更稳。

sklearn 的 SVC 内部默认用 OvO，LinearSVC 用 OvR。

小例子：0~9 共 10 类——OvO 训练 45 个二分类 SVM 投票，OvR 训练 10 个。

💡 提示：OvO 适合「每两类都好分」的情形；OvR 模型少，但每个子问题类别不平衡（一类 vs 其余）。

  1. 在实际项目中，你会先试 SVM 还是 KNN？为什么？
    - 提示：考虑数据量、维度、计算资源等因素

参考答案

看数据特征，没有绝对答案：

  • 数据小、维度低、分布不规则、想快速要个基线 → 先试 KNN（无需训练、直观），但务必标准化。
  • 维度高（如文本）、数据量较大、追求泛化 → 先试 SVM（高维稀疏用线性核，中等非线性用 RBF）。

计算资源也要考虑：KNN 预测慢、要存全部训练数据，大数据下吃力；SVM 预测只依赖支持向量、较快。实践中我常先跑一个简单基线（KNN 或逻辑回归），再用交叉验证对比 SVM，让数据说话。

小例子：1000 样本、20 维 → 两者都试 + CV；5 万维文本 → 直接线性 SVM。

💡 提示：两者都要先做特征缩放；用交叉验证决定，而不是凭感觉。
