5. memo 参数处理循环引用

sequenceDiagram participant User participant Deepcopy as copy.deepcopy participant Memo as memo 字典 participant Obj as 对象A User->>Deepcopy: deepcopy(对象A) Deepcopy->>Memo: 检查 id(对象A) Note over Memo: 未找到，继续拷贝 Deepcopy->>Obj: 拷贝对象A的属性 Deepcopy->>Memo: memo[id(对象A)] = 新对象A Note over Deepcopy: 发现循环引用 Deepcopy->>Memo: 检查 id(对象A) Note over Memo: 已找到，返回已拷贝的对象 
sequenceDiagram
    participant User
    participant Deepcopy as copy.deepcopy
    participant Memo as memo 字典
    participant Obj as 对象A

    User->>Deepcopy: deepcopy(对象A)
    Deepcopy->>Memo: 检查 id(对象A)
    Note over Memo: 未找到，继续拷贝

    Deepcopy->>Obj: 拷贝对象A的属性
    Deepcopy->>Memo: memo[id(对象A)] = 新对象A

    Note over Deepcopy: 发现循环引用

    Deepcopy->>Memo: 检查 id(对象A)
    Note over Memo: 已找到，返回已拷贝的对象
