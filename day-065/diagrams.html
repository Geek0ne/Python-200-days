3. 路由匹配机制详解

graph TD Start[用户请求: /user/张三] --> Match{URL 匹配} Match -->|精确匹配 /| R1["路由: /<br/>→ index()"] Match -->|精确匹配 /about| R2["路由: /about<br/>→ about()"] Match -->|变量匹配 /user/张三| R3["路由: /user/&lt;username&gt;<br/>→ show_user(username='张三')"] Match -->|变量匹配 /post/42| R4["路由: /post/&lt;int:id&gt;<br/>→ show_post(id=42)"] Match -->|无匹配| R5["→ 404"] R3 --> Execute1["show_user('张三')"] R4 --> Execute2["show_post(42)"] R5 --> Error["404 Not Found"] style Error fill:#ff9999 
graph TD
    Start[用户请求: /user/张三] --> Match{URL 匹配}
    
    Match -->|精确匹配 /| R1["路由: /<br/>→ index()"]
    Match -->|精确匹配 /about| R2["路由: /about<br/>→ about()"]
    Match -->|变量匹配 /user/张三| R3["路由: /user/&lt;username&gt;<br/>→ show_user(username='张三')"]
    Match -->|变量匹配 /post/42| R4["路由: /post/&lt;int:id&gt;<br/>→ show_post(id=42)"]

匹配顺序：Flask 按照路由定义的顺序进行匹配。先定义的路由优先级更高。

flowchart LR URL["GET /post/1"] --> Parse["解析 URL<br/>提取路径"] Parse --> MatchRoute["匹配路由表<br/>/post/&lt;int:id&gt;"] MatchRoute --> CallView["调用视图函数<br/>show_post(id=1)"] CallView --> QueryData["获取数据<br/>post = POSTS[0]"] QueryData --> RenderTemplate["渲染模板<br/>render_template()"] RenderTemplate --> Html["生成 HTML<br/>响应字符串"] Html --> Send["发送到客户端"] style Send fill:#90EE90

8. 蓝图（Blueprint）—— 模块化组织

大型 Flask 项目通过蓝图（Blueprint）来组织模块：

项目根目录/
│
├── app.py                  ← 创建 Flask 应用，注册蓝图
│
├── blog/                   ← 博客模块（蓝图）
│   ├── __init__.py         ← 创建蓝图对象
│   ├── routes.py           ← blog 的路由
│   └── templates/
│       └── blog/
│           ├── index.html
│           └── post.html
│
├── auth/                   ← 认证模块（蓝图）
│   ├── __init__.py
│   ├── routes.py           ← auth 的路由
│   └── templates/
│       └── auth/
│           ├── login.html
│           └── register.html
│
└── static/                 ← 全局静态文件
    ├── css/
    ├── js/
    └── images/
python
# blog/routes.py
from flask import Blueprint, render_template

blog_bp = Blueprint('blog', __name__, url_prefix='/blog')

@blog_bp.route('/')
def index():
    return render_template('blog/index.html')

# app.py
from blog.routes import blog_bp
app.register_blueprint(blog_bp)
