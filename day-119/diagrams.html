一、API 调用全流程

sequenceDiagram participant User as 👤 用户 participant App as 📱 你的应用 participant API as ☁️ LLM API participant Tool as 🔧 外部工具 User->>App: 输入问题 App->>API: POST /chat/completions<br/>(messages + tools) alt 普通回复 API-->>App: choices[0].message.content App-->>User: 显示回复 else Function Calling API-->>App: tool_calls: [{name, args}] App->>Tool: 执行函数(name, args) Tool-->>App: 返回结果 App->>API: 发送 tool 结果 API-->>App: 最终回复 App-->>User: 显示回复 end 
sequenceDiagram
    participant User as 👤 用户
    participant App as 📱 你的应用
    participant API as ☁️ LLM API
    participant Tool as 🔧 外部工具

    User->>App: 输入问题
    App->>API: POST /chat/completions<br/>(messages + tools)
    
    alt 普通回复
        API-->>App: choices[0].message.content
        App-->>User: 显示回复
    else Function Calling
        API-->>App: tool_calls: [{name, args}]
        App->>Tool: 执行函数(name, args)
        Tool-->>App: 返回结果
        App->>API: 发送 tool 结果
        API-->>App: 最终回复
        App-->>User: 显示回复
    end
